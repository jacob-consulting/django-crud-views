## Shared Patterns

- **Render-time purity:** adapter `_cv_button_context()` copies extras; normalizer owns effective presentation;
  render uses `render_to_string(..., data)` with normalized data only. No mutation of the adapter, context,
  public crispy input_type or template during rendering.
- **Import safety:** imports requiring the app registry remain inside render-time helpers. The registry and
  public form adapters remain importable before Django setup.
- **Validation and diagnostics:** explicit invalid values raise; selected invalid configuration follows strict
  mode versus logger fallback. Accept only exact `button`/`a`; None is inheritance, not invalidity.
- **Escaping:** preserve the existing `_literal`/attribute normalization/flatatt pipeline and template autoescape.
  Never mark supplied labels, URLs or attribute values safe. Attribute filtering is scoped to actual anchor output.
- **Authorization:** no new guard is introduced. Existing permission-aware destination construction remains
  upstream; this phase changes rendering of that existing destination.
- **Verification boundary:** extend existing pytest/lxml tests and executable recipes. Retain default golden
  bytes and the existing JavaScript handler. Native no-JS/new-tab navigation still requires browser acceptance.
