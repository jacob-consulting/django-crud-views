> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Developer configuration -> renderer | Raw tag intent (`tag=`, `cv_tag`) and the `form:cancel-tag` class-table value select native markup | Developer configuration (trusted code, may be malformed) |
| Form state -> browser | Disabled and submit/reset semantics must survive presentation selection | Form control semantics |
| Attribute/label values -> HTML | Applications may supply untrusted literal values; attribute names remain developer code | Possibly untrusted text in attributes and labels |
| Normalized form context -> custom leaf | Only the finite `FORM_LEAF_KEYS` contract crosses; caller context stays private | Template context |
| Published recipe -> downstream application | Copyable examples must preserve normalization and destination trust | Documentation code |
| DOM click -> package listener/browser | Native links must not inherit button navigation interception | Browser navigation |
