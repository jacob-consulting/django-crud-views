## Adapter mechanics

An explicit private helper alone cannot pass destination parent A through an existing application override `cv_has_access(user, obj_B)` without either adding a rejected keyword, substituting obj, or bypassing the override. Use the private ContextVar only for that compatibility seam. Ordinary code still passes explicit resolver inputs; no ambient context enters request-free ViewSet.get_url.

Open one scope around one URL/access/state action assembly. Match by target class, user identity and original object identity; store the rendering view and explicit child-parent role. Stock cv_get_router_and_args/cv_get_child_url publish the exact selected resolution. The getter lazily invokes the same resolver when an instance URL override did not publish one, using the semantic target and page scope; it does not parse arbitrary custom URL destinations or claim they are certified. Such overrides remain responsible for their routing policy; protected previews separately certify their exact candidate in plan 04.

ContextVar values are immutable frames. Publishing replaces the frame rather than mutating a frame shared by copied contexts. The manager always resets its original token in finally. The owner thread and asyncio task identities prevent an inherited/copied frame being consumed by another concurrent execution owner. A nested scope restores the outer frame. No user permissions/results are stored. A user/target/object mismatch returns no matching frame and uses normal resolution/fallback behavior.

The existing custom cv_has_access override runs exactly once with its original arguments. Guardian's cooperative super() path reads the matching resolution in plan 03. Existing custom overrides that intentionally do not delegate retain responsibility for their policy. State and label hooks still receive their established action object; nested create remains the existing explicit parent-state exception. No class attribute mutation, temporary monkeypatch or second invocation of access to recompute another parent.
