- **Form ownership:** existing page form/CSRF/crispy renderer owns submission; frames only decorate. Workflow ordinary/modal branches remain distinct.
- **Escaping:** render ordinary template variables and safe-mark only the completed renderer result as existing code does.
- **Verification:** follow RESEARCH.md's source-loaded four-worker commands; no broad tests were run for this map. Update goldens only for intended output changes. Documentation delivery includes settled keys, optional-app ownership and frame contract; a Breaking entry requires migration guidance.
