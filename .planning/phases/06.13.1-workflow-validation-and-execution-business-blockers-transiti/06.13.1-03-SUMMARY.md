## Template Contract for Plan 05

Public override path: `crud_views_workflow/widgets/transitions.html`. The only named block is **`actions`**, surrounding the ordered action loop. The template owns no outer form, CSRF token, alternate transition input or generic submit.

- `widget.name`: actual HTML field name, including any form prefix.
- `widget.attrs`: normal widget attributes including the group ID, classes and composed description references. Preserve these when overriding; retain invalid state without text-input styling.
- `widget.label`: escaped final field label; render normally, without applying a second unconditional escaping pass. It names the group and matches the visible field label.
- `widget.help_text`, `widget.help_id`: optional raw general guidance and its unique ID; guard truthiness and force-escape the content.
- `widget.comment_required`: whether any offered action requires a comment; controls the single translated legend.
- `widget.actions`: ordered list of offered actions. Each action has `name`, `label`, `id`, `help_text`, `help_id`, `blockers`, `blockers_id`, `comment_required`, and `describedby`.
- `action.name` is the exact submitted transition method name. `label`, `help_text` and each ordered blocker are literal text. `describedby` composes preserved external descriptions, general guidance, applicable field-error paragraphs and that action's own help/blocker IDs.
- The native button is disabled for business blockers or a disabled widget, not for an initially empty required comment. Keep a visible full label and existing `form:submit`, `form:hidden-label` and `form:cancel` theme conventions.
- Source translation msgids introduced here: **`Comment required`** and **`* Comment required`**. Plan 05 supplies German PO/MO updates.

## Custom Renderer and Keyboard Boundaries

- Supported custom forms retain the constructor, fields, `get_layout_fields`, `clean`, radio `submit_label`, and `get_submit_button` hooks. Button-mode `get_form_actions` deliberately does not invoke the generic submit hook.
- A replacement helper/action-row implementation that bypasses `get_form_actions`, or a renderer that bypasses the selected transition widget, must adopt the button-mode contract itself. No arbitrary layout traversal or helper mutation is attempted. Explicit custom field/widget/Cancel IDs remain the custom renderer's uniqueness responsibility.
- Namespace identity exists before subclass field access. Later configuration clears form BoundField presentation caches without rerunning clean; a separately retained pre-rendered HTML string is not retroactively rewritten.
- Native Enter in a required single-line custom field may activate the first enabled-in-place submit control in tree order and send its real name/value. Browsers do not skip a disabled first submit to find a later enabled alternative. This differs from an omitted-name POST, which the server rejects. The stock comment textarea uses Enter for a newline. Plan 04 must prove actual keyboard behavior; no sentinel/default submit, hidden transition or workflow JavaScript was added.

Raw bound comment data and direct native-widget rendering retain the original tabs/spaces; meaningful comment and custom-field text remain exact in the response. This existing generic renderer behavior was preserved.
