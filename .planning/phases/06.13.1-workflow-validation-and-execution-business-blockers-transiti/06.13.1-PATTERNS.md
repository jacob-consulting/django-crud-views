    except KeyError:
        raise AttributeError(f"module {__name__!r} has no attribute {name!r}") from None

## Shared Patterns

- **Security first:** existing available-user FSM transitions determine offered choices; workflow_has_transition rechecks execution before business validation/getattr. Unauthorized blocker text must never be computed or disclosed.
- **Translation and errors:** gettext_lazy imports and form.add_error above are the concrete established patterns. Preserve message order and raw bound input; ordinary execution ValidationError propagates.
- **Atomic lifecycle:** existing view writes and on_transition belong to one supported database transaction. Success callbacks must be registered only after successful processing.
- **Form ownership:** reuse cv_form_body/cv_render_form; render through the shared form/widget path so modal and page remain aligned. Do not clear custom layouts or add nested forms.
- **Maintainability:** private refusal type and private execution integration are bounded workflow additions; no generic form-view refactor or public exception framework.
