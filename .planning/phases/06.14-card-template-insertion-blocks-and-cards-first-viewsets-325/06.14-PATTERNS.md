## Shared Patterns

- **Authentication/authorization:** Use permission-required view classes and `user_viewset_permission`; `test_card_blocks.py:21–28` shows a real logged-in Django client. Do not replace destination authorization with link visibility.
- **Validation/errors:** Preserve existing Django view/permission handling. Assert 200/302/403 HTTP outcomes; no service layer, wrapper or new error type belongs here.
- **Escaping/CSRF:** Default Django interpolation plus inherited action/form rendering. Normalize only masked CSRF values in comparisons.
- **Navigation:** Home, breadcrumbs, Save and Cancel are separate existing contracts. The secondary view's `cv_home_key` does not alone drive all four. Default Save remains cards even when explicitly allowed origin-aware Cancel returns to table.
- **State:** Use existing per-view persistence; capture a table-origin form link and follow its emitted Cancel URL. Do not merge sibling filters/order/page state.
