## Shared Patterns

- **Entry points:** mixin passes `view=self` at `mixins.py:69`; raw tag passes `context.get("view")` at tag lines 27–30. Already-resolved groups bypass resolution. Resolve help policy once, never in layouts.
- **Validation:** existing Pydantic config normalization and lazy text validation remain authoritative. Add strict boolean instructions only for detail.
- **Raw inputs:** link/badge callbacks use stored values; explicit badge labels retain precedence. Display text is additive.
- **Permissions:** no new authentication or guards. Preserve existing complete-view/extension composition.
- **Performance:** preserve ordinary traversal query costs; use existing query assertion fixtures for loaded/uncached paths. Broad verification uses bounded multicore pytest while resources are shared.
