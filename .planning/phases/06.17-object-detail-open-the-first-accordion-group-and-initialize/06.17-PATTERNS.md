## Shared Patterns

- **Identity and selection:** presentation.py owns component/group identity and first selection; templates consume projected entries. No configuration/schema addition.
- **Error handling:** absent component/adapter no-op where specified; present component/adapter exceptions propagate. No catch wrapper or fallback global.
- **Lifecycle:** existing repeat guard, DOM ready, loaded and attached-content unload boundary. Initialization never activates a tab or takes focus.
- **Validation/security:** preserve autoescaping, scoped references, nearest-tablist ownership and hostile-context tests. Authentication/authorization requires no change in this phase.
- **Asset registration:** `tests/test1/od/test_presentation_assets.py` lines 15–21 already asserts one script emission and order; extend order coverage to adapters. Preserve apps.py registry path and reset/repopulation tests.
- **Maintainability:** modify bounded existing seams, no new namespace registry, accordion JavaScript, keyboard handler or generic tab abstraction.
