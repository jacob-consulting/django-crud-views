## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Filter-list fixtures without a helper failed on crispy-forms before 2.7**
- **Found during:** Task 2, the first replay at `e3b7e431` (Django 4.2: 6 cases, 6.0 crispy floor: 6 cases).
- **Issue:** the filtered child lists in `test_ancestor_resolution.py` declared no `formhelper_class`. crispy-forms 2.5 and 2.0 raise `VariableDoesNotExist` for `filter.form.helper`, while 2.7 swallows it. The underlying behavior predates this phase.
- **Fix:** the fixtures declare the documented `ListViewFilterFormHelper` subclass. The package behavior is logged in `deferred-items.md`.
- **Files modified:** `tests/test1/test_ancestor_resolution.py` (outside the plan's file list; required for the supported-series gate).
- **Verification:** the module passes on 4.2, 5.2 and 6.0, and the full replay was rerun.
- **Committed in:** `5829cae7`

**2. [Rule 3 - Blocking] Django 4.2 error reporting read the refused queryset after the refusal**
- **Found during:** Task 2, the first replay (Django 4.2: 14 cases in `test_ancestor_databases.py`).
- **Issue:** a refusal is an `ImproperlyConfigured` 500. Django 4.2's `AdminEmailHandler` builds an `ExceptionReporter` even without `ADMINS`; Django 5.x returns early. The report's frame `repr()` evaluated the refused querysets, so the "no shard SQL" captures counted Django's error report rather than package work.
- **Fix:** an autouse fixture in that module turns the handler into a no-op, matching 5.x without `ADMINS`. The Django 4.2 deployment caveat is logged in `deferred-items.md`.
- **Files modified:** `tests/test1/test_ancestor_databases.py` (outside the plan's file list).
- **Verification:** the module passes on all three series, and the full replay was rerun.
- **Committed in:** `5829cae7`

**3. [Rule 2 - Hand-off] `docs/reference/nested.md` was edited outside the plan's file list**
- **Found during:** Task 1, as the 06.18-11 hand-off.
- **Fix:** the Databases section links `../migrating-1.0.md#nested-write-database-selection`, which the new pairing test asserts.
- **Committed in:** `e3b7e431`

**4. [Evidence path] `evidence/06.18-12/` and `deferred-items.md`** were added as evidence and log paths, as in plans 01–11.
