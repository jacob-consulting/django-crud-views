## Pattern Assignments

### Policy values, ViewSet registration, settings

**Analog:** `src/crud_views/lib/viewset/parentviewset.py`, lines 13–21, 23–33:

```python
class ParentViewSet(BaseModel):
    name: str  # the name of the parent ViewSet
    attribute: str | None = None
    pk_name: str | None = None

    @field_validator("attribute", mode="plain")
    @classmethod
    def validate_attribute(cls, value: Any) -> Any:
        if value is None:
            return value
        if not REG_ATTRIBUTE.match(value):
            raise ValueError(f"attribute must be lowercase alpha with underscores at {cls}")
        return value
```

Excerpt omits comments/intervening fields. Follow typed dependency-light Pydantic values and `ValueError` validation style. The new pair/policy need stricter validation than this analog: reject extras, coerced booleans, incomplete/None pairs and padded keys; use fresh dictionary/policy defaults. Keep these values execution-free. Settings must import the dependency-light value module, not ViewSet.

### Metadata walk and one request engine

**Analog:** `src/crud_views/lib/viewset/parentviewset.py`, lines 47–66:

```python
@property
def viewset(self) -> "ViewSet":

def get_pk_name(self) -> str:
    return self.pk_name if self.pk_name else f"{self.viewset.name}_pk"

def get_attribute(self) -> str:
```

Use declared edge metadata and late registry resolution. Add a bounded visited-identity walk; do not copy existing unbounded parent loops. Structural validation must not inspect database-backed `permissions`.

### MRO bridges and independent local gates

**Analog:** `src/crud_views/lib/view/base.py`, lines 262–267:

```python
def dispatch(self, request, *args, **kwargs):
    self._cv_consume_cancel_restore(request)
    response = super().dispatch(request, *args, **kwargs)
    if self.cv_modal:
        patch_vary_headers(response, ["X-CV-Modal"])
    return response
```

Preserve cancel/modal processing and cooperative super calls. The engine needs an idempotent view-instance success guard callable from earlier bridges. Core `CrudViewPermissionRequiredMixin.has_permission()` (lines 1077–1087) calls `cv_get_action_object()` and state hooks; it cannot discover early actor admission safely. Manage inherits `PermissionRequiredMixin` before `CrudView` (manage.py:10), so a core-only dispatch hook is too late. Guardian parent dispatch also runs earlier (mixins.py:327–336). Plan explicit early bridges for all three plus plain CrudView, sharing one engine.

Manage's real local admission can be public (`manage.py:30–39`); preserve that behavior for all-none ancestry. Inheritance alone does not establish login requirements. Top-level requests retain their existing lifecycle. Denial must precede Resource loading and editor fragment work.

### Guardian provider and immediate-parent consumers

**Analog:** `src/crud_views_guardian/lib/mixins.py`, lines 62–72:

```python
def _check_object_perm(self, user, perm: str, obj) -> bool:
    if _guardian_inactive_actor(user):
        return False
    # Check model-level perm first, without obj.
    if self.cv_guardian_accept_global_perms and user.has_perm(perm):
        return True
    from guardian.core import ObjectPermissionChecker

    checker = ObjectPermissionChecker(user)
```

Comment shortened. Reuse the explicit model-OR-object shape and lazy optional import, but read the ancestor's policy fallback rather than this endpoint-local flag. Preserve inactive denial before superuser shortcuts; request-scope any checker cache. Resolve keys through the selected ancestor's permission map (Guardian content-type semantics live in `src/crud_views_guardian/lib/viewset.py:79–106`). Runtime missing keys become `ImproperlyConfigured`, not weaker fallback.

Replace old parent permission traversal, retaining independent Guardian composition, child object/queryset, actor and parent-state gates. Existing nested `has_permission` bypass at mixins.py:321–325 is important for create: do not accidentally impose child model-add. Helpers consult only immediate parent provider/fallback and target nearest requirement; none skips only that gate. Preserve unavailable/False for missing context, expose invalid configuration, and never guess ambiguous M2M parents. Manage context should report ancestor policy independently from remaining local Guardian flags.
