## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Declaration/URL/actor → framework | Untrusted URL coordinates (parent PKs), ViewSet declarations and actor permission inputs reach configuration validation, ORM lookups and local lifecycle gates | URL path parameters, policy declarations, user/group/object grants (authorization-sensitive) |
| Framework → provider/queryset | The framework hands resolved ancestors to the core/Guardian provider and child queryset; scope, identity and independent authorization must be preserved at each reached consumer | Ancestor/child model instances, auth records, database aliases (tenant/authorization-sensitive) |
