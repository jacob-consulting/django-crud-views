# Phase 06.19 Plan 01: Table honours Meta.sequence and omits the Actions column for cv_list_actions = None Summary

**`crud_views.lib.table.Table` now honours a subclass's `Meta.sequence`, appending `actions` last unless the sequence names it, and drops the `actions` column only when the owning view sets `cv_list_actions = None`. It does this through two `cv_` helpers and an order-preserving `exclude` merge (#337).**

## Accomplishments

- `Table.cv_default_sequence()` replaces the unconditional `("...", "actions")` default. Tables without `Meta.sequence` keep exactly the old order, so existing tables and goldens are unchanged.
- `Table.cv_exclude_actions(view)` plus the `exclude` merge in `Table.__init__`: `None` removes the column, while `[]`/`()` and views without the attribute keep it. `Meta.exclude` and a caller `exclude` survive.
- The 15-test module covers construction with a `SimpleNamespace` stub plus one `/author/` request test via `monkeypatch`, with no new ViewSet or view.
- Docs: CHANGELOG `### Changed` bullet, the `### Column order and the actions column` subsection (it states the decision is static, not per user), and the Resource example on `None`.
