# Phase 06.19 Plan 02: Gap closure for the no-ellipsis sequence and the None/str exclude kwarg Summary

**`Table.cv_default_sequence()` now inserts `"..."` before `actions` for a `Meta.sequence` without one, so `actions` really is last. `Table.__init__` now normalises a `None` or `str` caller `exclude` before merging in the `actions` exclusion, which closes both `gaps:` entries in 06.19-VERIFICATION.md (WR-01, WR-02, WR-03).**

## Accomplishments

- Gap 1 (WR-01): `NoEllipsisTable` with `Meta.sequence = ("last_name",)` now renders `last_name, id, first_name, actions` instead of `last_name, actions, id, first_name`. `cv_default_sequence()` returns `("last_name", "...", "actions")`. `PlainTable`, `SequencedTable`, `MiddleEllipsisTable` and `ActionsFirstTable` behave as before.
