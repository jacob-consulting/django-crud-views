### `src/crud_views/lib/table/table.py` (Table subclass, construction-time transform)

**Analog:** the file itself — `src/crud_views/lib/table/table.py` (41 lines, fully read).

**Current state to replace** (lines 23-34):
```python

    """
    Table with action column
    """

    actions = ActionColumn(verbose_name=_("Actions"))

    def __init__(self, *args, **kwargs):
```

**View-kwarg contract that must be preserved** (lines 15-20, `TableWithViewContext.__init__`):
```python
    def __init__(self, *args, **kwargs):
        if "view" not in kwargs:
            raise ValueError(f"view not set in {self.__class__}")
        view = kwargs.pop("view")
        super().__init__(*args, **kwargs)
        self.view = view
```
Why it matters: `Table.__init__` runs before this, so it must use `kwargs.get("view")` — never `pop` — or the
`ValueError` guard and `self.view` assignment break. The plan's `self.cv_exclude_actions(kwargs.get("view"))` does
exactly that.

**Existing staticmethod style on the same class** (lines 36-41) — keep untouched, place the new helpers next to it:
```python
    @staticmethod
    def order_actions(queryset, is_descending):
        """
        do not order actions
        """
        return queryset, True
```

**"Default a kwarg only when absent" idiom used throughout the package** (`src/crud_views/lib/table/columns.py`
lines 14-21, `ActionColumn.__init__`):
```python
    def __init__(self, **extra):
        if "orderable" not in extra:
            extra["orderable"] = False
        if "template_name" not in extra:
            extra["template_name"] = "crud_views/columns/actions.html"
        if "attrs" not in extra:
            extra["attrs"] = ColAttr.action
        super().__init__(**extra)
```
Replicate: `if "sequence" not in kwargs:` stays the guard (D-03: a caller `sequence` wins unchanged).

**Imports** (lines 1-5) — no new imports are needed for the change; `tuple`/`dict.fromkeys` are builtins:
```python

from django.utils.translation import gettext_lazy as _

from .attrs import ColAttr
from .columns import ActionColumn
```

**django-tables2 facts confirmed in the installed package** (`.venv/.../django_tables2/tables.py`):
- `TableOptions.__init__` line 137: `self.exclude = getattr(options, "exclude", ())`
- `TableOptions.__init__` line 149: `self.sequence = getattr(options, "sequence", ())`
- `Table.__init__` line 282: `self.exclude = exclude or self._meta.exclude` — confirms D-05: passing `exclude`
  alone would drop `Meta.exclude`, so the merge `(*self._meta.exclude, *kwargs.get("exclude", ()), "actions")`
  deduped with `dict.fromkeys` is required.
- `cls._meta.sequence` is `()` when undeclared, so `tuple(cls._meta.sequence or ())` → empty → return the
  historical `("...", "actions")` (D-02).

**Docstring convention:** existing docstrings in this file are triple-quoted, multi-line, short. The plan's one- or
two-line docstrings for `cv_default_sequence` / `cv_exclude_actions` fit; keep lines ≤ 120 chars.

**Public surface:** `src/crud_views/lib/table/__init__.py` exports `Table` already; no `__all__` change.

```python
class Header:                                   # lines 5-20
    @property
    def text(self) -> bool:
        return self.element.text_content().strip()

    @property
    def is_action(self) -> bool:
        return self.text == "Actions"


class Table:                                    # lines 130-175
    def __init__(self, response):
        self.content = response.content.decode("utf-8").strip()
        self.html = html.fromstring(self.content)

    @property
    def headers(self) -> list[Header]:
        return [Header(header) for header in self.thead.xpath("//th")]

    @property
    def action_index(self) -> int | None:
        for index, header in enumerate(self.headers):
            if header.is_action:
                return index
```
`action_index` falls through to `None` when no header reads "Actions" — the assertion the plan uses
(`assert rendered.action_index is None`). Caveat for the executor: `headers` uses the document-wide `//th` xpath,
and `Row.actions` indexes `self.columns[self.action_index]`, so do **not** call `rendered.rows[i].actions` in the
`None` case (it would raise). Asserting on `action_index` and `[h.text for h in rendered.headers]` is safe.
Import alias in the plan (`from tests.lib.helper.boostrap5 import Table as RenderedTable`) avoids clashing with
`crud_views.lib.table.Table`; keep it.
