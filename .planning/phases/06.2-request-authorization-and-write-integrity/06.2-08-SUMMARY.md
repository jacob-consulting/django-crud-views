## Accomplishments

- `get_context_data` calls the existing collection override once and always publishes `has_protected_objects`. Filtering, labels, tree and summary keys remain behind `cv_show_related_objects`; unfiltered protected instances never enter context. Default collection retains `router.db_for_write` and full NestedObjects materialization even with previews disabled.
- Custom protection retains precedence. A valid database-blocked POST uses the existing full-page 200/modal 422 response shape, invokes no write hooks and keeps storage intact. Invalid confirmation still runs the invalid hook/path. A blocked page omits the whole form, including confirmation, submit and form-contained cancel.
- Default `cv_form_valid` captures the bound target delete and native graph eligibility before calling it exactly once. Only eligible metadata plus exact target Model.delete, Collector type/origin and immediate/terminal Collector.collect frames produce `_TargetDeleteBlocked`; `post` catches only this marker after the unchanged write boundary unwinds.
- The metadata traversal covers concrete parents, reverse native FK/one-to-one relations, hidden through rows, empty cascade branches and cycles. Custom handlers, SET closures, SET_DEFAULT, private bulk collectors, nonstandard managers/querysets/init/from_db and initialization listeners are ineligible. Unknown collector subclasses and non-target traceback identities fail closed by propagation. No new transaction is introduced for `cv_atomic=False`.
- Real-commit tests exercise both error classes and atomic modes: commit callbacks (including actual unrelated protected deletes), success hooks, model overrides before/after delegated deletion and writes before protected super calls, pre/post-delete signals, signal-registered commit callbacks and successful 302/204 hook order. The existing transaction module remains unchanged.
- Collection-extension regressions prove side-effect writes survive only when atomic is off. Cases include custom direct/nested handlers, an unrelated protected deletion, a nested BookNote handler, write-and-return beside native protection, SET(callable), callable SET_DEFAULT and custom from_db. ProtectedError aggregation is asserted as a new exception with retained members and a terminal collector frame; unaggregated RestrictedError retains identity. A handler restoring itself to CASCADE cannot retroactively certify the pre-call graph.
- Core, Guardian, all three actor-matrix families and the native alert override now pin the safe blocked response. Native overrides render escaped `alert.text`; exact headings distinguish hidden and labelled branches.
