## Blank check on lazy values

Probe (in-session): with settings configured and apps not ready, `str(gettext_lazy("subscription"))` raises
`AppRegistryNotReady`, and so does the same call inside `translation.override(None)`.

| Option | Description | Selected |
|--------|-------------|----------|
| Plain str only | A plain `str` that is `""` or whitespace-only raises `ValidationError`. Lazy values are accepted without a check, and the docs say so. Nothing is evaluated at import. | ✓ |
| Plain str + system check for lazy | Same validator, plus a system check that evaluates lazy values at startup. Adds a check ID, a test and docs. | |
| Evaluate lazy at construction | Literal reading of #338. Raises `AppRegistryNotReady` for any ViewSet built during app loading. | |

**User's choice:** Plain str only
