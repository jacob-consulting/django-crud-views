<objective>
Make the snippets a view renders for its own page — header, paragraph, list/card filter header, success and error
message — able to reference the view instance and, on a child ViewSet, the parent object. The only `src/` change is
`CrudView.cv_get_meta()` in `src/crud_views/lib/view/base.py`: it adds `view = self` and, when the ViewSet has a
parent, `parent_object = SimpleLazyObject(self.cv_get_parent_object)` (D-04). Everything else already exists:
`cv_get_parent_object()` reuses the ancestor guard's resolved parent or falls back to `get_object_or_404` (D-07), and
Django's `SimpleLazyObject` defers the call until a template actually touches the value.

Purpose: texts such as `"New book for {{ parent_object }}"` and `"Created {{ view.duplicate }} from {{ object }}"`
render their values instead of coming out empty (issue #339, tabler-test finding 29), while default snippets stay
byte for byte unchanged and class-level labels keep their context (D-02).

Output: the four-line `cv_get_meta()` change plus one new test module `tests/test1/test_snippet_context.py` covering
ROADMAP success criteria SC-1..SC-4 and decision D-07. Docs and changelog are plan 06.21-02.

Coverage contract note: this phase has no requirement IDs (`Requirements: TBD`) and no SPEC.md; the spec-less probe
fallback was skipped (visible, recorded choice). The contract is ROADMAP SC-1..SC-5 plus CONTEXT D-01..D-08.
</objective>
