# Phase 06.21 Plan 01: Snippet context exposes `view` and lazy `parent_object` Summary

**`CrudView.cv_get_meta()` now adds `view = self` and, on a child ViewSet, `parent_object = SimpleLazyObject(self.cv_get_parent_object)`. Header, paragraph, filter header and message snippets can render `{{ parent_object }}` and `{{ view.<attr> }}`. The parent is never resolved unless a snippet references it, and it costs no extra query while the ancestor guard state is present.**
