**Core pattern — current method to extend** (`base.py:1096-1107`):
```python

        """
        Metadata from ViewSet plus ViewContext
        """
        context = self.cv_get_view_context()
```

Add after the `object` block (D-04/D-07; shape verified by the research probe):
```python
        data["view"] = self
        if self.cv_viewset.has_parent:
            # lazy: a snippet that never mentions it never resolves the parent; one that does reuses the
            # ancestor guard's resolved parent (no query) or falls back to cv_get_parent_object()'s 404
            data["parent_object"] = SimpleLazyObject(self.cv_get_parent_object)
```

**Reused resolver — do not duplicate** (`base.py:1112-1131`). Pass the bound method as-is; no lambda, no try/except:
```python
    def cv_get_parent_object(self) -> Model:
        self.cv_assert_parent()

        resolved = _resolved_parent(self)
```

**Comment style** — short `# ...` line comments above a block (see `# add view specific data`, `# reuse the parent the ancestor guard resolved ...`). Docstrings are triple-quoted, one sentence.

**Render path that consumes the dict** (`base.py:525-539`) — `template_code` goes through `Template(...).render(TemplateContext(data))`, `template` through `render_to_string(template, data)`; both proxy a `SimpleLazyObject` on first access. ## Shared Patterns

### Instance vs class-level render split (scope guard for D-01/D-02)
**Source:** `src/crud_views/lib/view/base.py:541-591`
**Apply to:** the `base.py` edit and the AC4 test
Instance snippets call `self.render_snippet(self.cv_get_meta(), ...)`; class labels call `cls.render_snippet(cls.cv_viewset.get_meta(context), ...)`. Only the former path gains keys. Verify with `grep -n "cv_get_meta\|cv_viewset.get_meta" src/crud_views/lib/view/base.py`.

### Lazy value, unguarded failure
**Source:** `src/crud_views/lib/view/base.py:1112-1131` + `django.utils.functional.SimpleLazyObject`
**Apply to:** `cv_get_meta`, D-07 test
`SimpleLazyObject(self.cv_get_parent_object)` — bound method passed directly. `Http404` propagates out of `Template.render()` (it lacks `silent_variable_failure`); the test pins this with `pytest.raises(Http404)`.

### Per-test class patching
**Source:** `tests/test1/test_action_menus_context.py:43-44`
**Apply to:** every E2E test that changes `cv_*_template_code` or `action`
`monkeypatch.setattr(ViewClass, "attr", value)`; never direct assignment.

### Query attribution
**Source:** `tests/test1/test_ancestor_costs.py:36-40`
**Apply to:** AC2 E2E
`CaptureQueriesContext(connection)`; filter `captured_queries` by `'"app_publisher"' in q["sql"]`; compare before/after counts rather than asserting an absolute budget.
