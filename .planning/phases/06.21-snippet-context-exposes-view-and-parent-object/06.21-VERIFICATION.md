# Phase 06.21: Snippet context exposes `view` and `parent_object` (#339) Verification Report

**Phase Goal:** The snippets a view renders for its own page (header, paragraph, filter header, success and error
message) can reference the view and, on a child ViewSet, the parent object: `CrudView.cv_get_meta()` adds `view` (the
instance) and a lazy `parent_object`, so texts such as `"New order for {{ parent_object }}"` and
`"Created {{ view.duplicate }} from {{ object }}"` render instead of coming out empty. Default snippets render byte
for byte as today. Issue #339.
