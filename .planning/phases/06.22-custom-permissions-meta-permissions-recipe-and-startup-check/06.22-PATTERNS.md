    if viewset.parent is None:

## Shared Patterns

### Check message construction
**Source:** `src/crud_views/checks.py` 71-75 (E267/E268) and `src/crud_views/lib/viewset/__init__.py` 239-243 (E260 hint)
**Apply to:** both E269 halves
```python
Error(message, hint=hints[code], obj=viewset, id=f"viewset.{code}")
```
Always `obj=viewset` (tests filter on `m.obj.name`); hint spells out the fix ("add (...) to X.Meta.permissions, or use
the non-PermissionRequired view variant"). For proxies name the *concrete* model (`opts.object_name`, `opts.label`,
`opts.model_name` from `model._meta.concrete_model._meta`; Pitfall 2).

### Static, database-free selection
**Source:** `src/crud_views/lib/ancestors.py` 86 (`_walk_ancestors`), 343-356 (`_effective_provider`, `_selected_gates`), 310-334 (`_operation_requirements`, `_effective_pair`)
**Apply to:** pair half of E269. Reuse these; do not re-derive cascade/nearest/higher. Read only `_meta`, never
`Permission`/`ContentType` rows (06.18 rule; `no_db` tests enforce it).

### Guardian detection without importing guardian
**Source:** `src/crud_views/lib/viewset/__init__.py:71` (`_ancestor_provider: ClassVar[str] = "model"`),
`src/crud_views_guardian/lib/viewset.py:62` (`= "guardian"`), `ancestors.py:343-345`
**Apply to:** both halves — skip when `type(vs)._ancestor_provider != "model"`; for ancestors additionally skip
`_effective_provider(ancestor) == "none"` and `ancestor.is_resource`.

### Registry isolation in tests
**Source:** `tests/test1/test_ancestor_operations.py` 54-89 (`sfx`, `registry`, `no_db`), 92-97 (`_view`), 397-400 (`_ours`)
**Apply to:** `test_permission_declarations.py`, the added `test_missing_permission_access.py` test (its fixture already
pops its ViewSet), the docs-exec test (`_published_registry` restores everything). Never leave a test ViewSet in
`_REGISTRY`; restore `check_module._VOCAB_CACHE`.

### Executed docs fences
