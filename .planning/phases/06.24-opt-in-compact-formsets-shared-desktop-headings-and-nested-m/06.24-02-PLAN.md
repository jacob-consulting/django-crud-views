## Delegated support decisions

Exact stock widgets: django.forms.TextInput, NumberInput, DateInput and Select only, with their stock
template_name and, for Select, option_template_name and single-selection shape. Preserve attrs and choices;
ordinary ModelChoiceField using exact Select is supported. Reject subclass/custom-template variants, altered
input_type, checkbox/radio/multiple inputs, MultiWidget, files, passwords, Textarea and every unlisted visible
widget. Hidden fields are payload, not compact columns. No automatic renderer fallback.

Metadata constructors and get_form_kwargs(None) must be query-free and provide index-independent field names,
labels, types, required state and widget shape. Custom add_fields changes to compact columns are unsupported.
This is an explicit application support condition, not a generic promise that arbitrary Python constructors
cannot query. Across separate requests, uniformity is the application's contract; do not introduce a schema
token, cross-request cache, extra HTTP check or SQL interception to compare an old page with a new fragment.
