## Deviations from Plan

### 1. [Rule 1 - Bug] Unmarking a row could delete its persisted parent

- **Found during:** Task 3 real browser FormData POST and original-parent retention assertion.
- **Issue:** Hidden DELETE unmark emitted `"0"`. Django creates a fresh CheckboxInput for POST and treats that nonempty string as checked; the unmarked parent was deleted with its children.
- **Fix:** Hidden unmark emits `""`; marked value remains `"1"`. Native checkbox handling, authorization and saving are unchanged. The paired real-POST matrix now toggles and unmarks the original parent in all classic/compact/capability combinations and proves it survives.
- **Files:** `src/crud_views/static/crud_views/js/formset.js`, focused unit/integration/Python regressions.
- **Commits:** `bd9a2aeb`, `e4d07fa9`. All 383 JS tests, the 12-case real POST matrix and final browser lifecycle pass.

### 2. [Rule 3 - Blocking fixture] Restore the disposable host's current page contracts

- **Found during:** Tasks 1 and 3.
- **Issue:** The historical host had no usable registered Cancel destination; its main crispy helper also emitted CSRF in addition to the explicit page token.
- **Fix:** The fixture resolves Cancel to its own editor path and disables helper CSRF, leaving the explicit token. Package CSS loads after Bootstrap. Edge policies use dedicated disposable paths so genuine AJAX retains the fixture selection when the controller uses the owning path.
- **Files:** existing browser server/page/runner only. No production view or permission policy changed.
- **Commits:** `d24d386d`, `01e65148`.
