## Necessary deviations and refreshed earlier browser evidence

1. **Invalid nested field crash:** both the classic example and an independent core BookNote test reproduced
   `InlineFormSet.clean()` accessing formset `cleaned_data` when child fields were invalid. The bounded fix
   returns before parent-presence validation when Django has recorded individual form errors, preserving the
   correctable error rather than raising AttributeError. No new API or save/permission path. This follows
   Django's [custom formset validation guidance](https://docs.djangoproject.com/en/5.2/topics/forms/formsets/#custom-formset-validation).
   Three machine-approved RED records are retained in `evidence/06-red-*.json`; core/existing classic and new
   compact regressions pass. A Fixed changelog entry records the behavior.
2. **Readable mobile comparison:** browser inspection found identical icon-only edit actions and host toolbar
   overflow. Existing `cv_context_actions_inline=[]` moves header choices into labelled More actions menus;
   the list uses existing per-key label modes. Both actions remain available. No new CSS, template, controller
   or menu mechanism was introduced. Final browser record shows zero page overflow at both widths.
