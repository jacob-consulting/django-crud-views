- Existing fragment URLs carry coordinates rather than the fixture's presentation query. For this opt-in Publisher only, a fragment request recovers composition from the same-origin, same-path editor Referer. Product routing and JavaScript remain unchanged.

No product CSS correction, custom widget, renderer, template, migration or dependency was needed. Existing compact score headings are dense at 768px; they are unchanged, pass their geometry contract, and remain part of later visual judgment.
