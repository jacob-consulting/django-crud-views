## Shared Patterns

- **Native request semantics:** `tests/lib/helper/forms.py`, 24–27, adds checkbox/radio payload only when `checked` is present. It does not filter disabled controls: remove disabled names explicitly for browser-equivalent payloads, then separately test forged values. Preserve Django parsing; no hidden false-value field.
- **Ownership and errors:** compact schema failures include declaration key/field (compact.py 77–78); help is escaped before crispy rendering (143–148). Test labels by `for=input.id`, field-owned help/errors, and full prefixed IDs/names. Keep hidden identity/DELETE controls outside compact columns.
- **Required and disabled:** use real BooleanFields and existing persisted/nonempty rows for required rejection. Do not require HTML `required` on formset rows. Disabled values must come from trusted initial state and survive omitted/forged POST.
- **Preserve existing paths:** keep marker admission, metadata/query tripwires, nesting, authorization and row lifecycle intact. No production template or JS change is indicated by this map.
