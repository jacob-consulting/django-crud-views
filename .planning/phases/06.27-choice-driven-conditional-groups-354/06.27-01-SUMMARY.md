## Decisions Made

Normalized string tokens keep browser/server matching explicit without reverse mappings. Native model-field conversion is admitted only for standard text/integer fields. Empty placeholders skip coercion; configured empty matches stay invalid. A typed empty sentinel colliding with a declared token is refused because absence and a real selection would be indistinguishable.
