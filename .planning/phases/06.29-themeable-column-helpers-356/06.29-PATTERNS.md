## Shared Patterns

- **Configuration/validation:** existing `button_classes.py` accessor, cache invalidation and system checks apply to every width. No parallel parser, registry or setting.
- **Isolation:** transient shallow rendering copies; preserve reusable layout state. Registry test fixtures snapshot, restore, and reset caches.
- **Encoding:** Django escapes classes/IDs; crispy owns rendered fields and flat attributes. Only already-rendered crispy content uses the existing safe-output contract.
- **Template ownership:** exact installed-source discrimination from `actions.py:25–38`; no global pack override or bridge-capability cache across loader changes.
- **Authentication/errors/logging:** no new auth, database, logging or error wrapper is needed for these layout utilities. Retain existing view permissions and rendering failure behavior.
