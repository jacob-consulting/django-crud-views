#### CR-01: Lazy caller classes now crash numbered-column rendering

**Classification:** BLOCKER
**File:** `/home/alex/projects/workspaces/cv-phase-06-29/django-crud-views/src/crud_views/lib/crispy/table.py:63`
**Related lines:** 39–44 retain the unconverted constructor argument as `_cv_extra_class`.
**Issue:** `Column6("name", css_class=gettext_lazy("extra"))` still constructs successfully, but its first render raises `TypeError: sequence item 1: expected str instance, __proxy__ found`. The new `str.join` consumes the raw Django lazy string rather than crispy's already-coerced caller contribution. Before this change, the thin `Column6` subclass delegated to `Div.__init__`, whose `self.css_class += f" {css_class}"` converted this value and produced `col-md-6 extra`. This regression requires no theme configuration and affects all twelve ordinary helpers. Lazy CSS arguments also have an established compatibility precedent in `tests/test1/test_crispy_buttons.py:587`; this is constructor input, not a non-string registry value rejected by E361.

**Reproduction:** Run this small script with the test project's settings and either supported environment above:

```python
from tests.test1.conftest import pytest_configure

pytest_configure()

from crispy_forms.layout import Column
from django.utils.translation import gettext_lazy
from crud_views.lib.crispy import Column6
from tests.test1.test_crispy_columns import render_column

OldColumn6 = type("OldColumn6", (Column,), {"css_class": "col-md-6"})
extra = gettext_lazy("extra")
render_column(OldColumn6("name", css_class=extra))  # succeeds
render_column(Column6("name", css_class=extra))  # TypeError at table.py:63
```

**Fix:** Normalize the retained constructor-extra contribution using crispy-compatible string coercion before joining it with registry classes. Preserve the existing constructor behavior, authored class ownership, and template escaping; do not silently drop the lazy value. Add a focused regression using a Django lazy string under default, themed, and suppressed width classes, including repeated renders. The expected outputs include `col-md-6 extra`, `span-6 extra`, and `extra`, respectively.
