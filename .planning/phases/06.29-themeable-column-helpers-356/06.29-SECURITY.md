# Phase 06.29 — Security

## Trust Boundaries

Config/authored values reach HTML attributes and crispy field output. Reusable layout objects cross into per-render projections. Application-selected templates must retain ownership. Published recipes become application configuration.

## Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation evidence | Status |
|---|---|---|---|---|---|---|
| T-06.29-01 | Tampering | HTML output | high | mitigate | Local leaf quotes/escapes css_id/css_class; crispy owns flat_attrs and fields. test_column_attributes_values_and_errors_are_escaped rejects injected nodes/attributes. | closed |
| T-06.29-02 | Tampering | Reusable state | medium | mitigate | _ThemedColumn.render copies before resolving classes; parent renderer isolates wrapper context. Tracer, all-width transitions, assignment and nested/sibling tests preserve state. | closed |
| T-06.29-03 | Tampering | Template selection | medium | mitigate | Exact installed origin/source/pack checks and explicit-template guard. Custom-template, same-name loader, changed-source, alternate-pack and missing-template tests verify boundaries. | closed |
| T-06.29-04 | Tampering | Published recipes | low | mitigate | test_column_registration_and_project_recipes executes actual unique fences, AppConfig.ready and project settings with isolated registry state. No escaping bypass recommended. | closed |
| T-06.29-SC | Tampering | Dependency installation | high | mitigate | No dependency installs or manifest changes. Both summaries record cached interpreters with worktree-local source. | closed |

## Verification Scope

Both plans authored this register. Shared T-06.29-SC is deduplicated into five unique threats. ASVS L1 source/test inspection confirms all mitigations, permitting direct closure without a deeper auditor dispatch. Inspected table.py, bootstrap5_column.html, column and recipe tests, and phase dependency diffs. Final floor selections passed 1,391 tests each; full Django 5.2 suite passed 12,868 with one existing version skip. Application-authored templates and arbitrary future packs are outside this bounded helper guarantee. No new authentication, persistence or permission boundary.
