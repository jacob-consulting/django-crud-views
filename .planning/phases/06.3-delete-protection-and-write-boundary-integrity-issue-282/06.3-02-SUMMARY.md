## Accomplishments

- Moved/re-exported `RelatedObjects` with its original tuple shape. Added immutable boundary, contribution
  and inspection records, native metadata traversal, additive provider merging, and a native write adapter.
- Inspection handles ordinary CASCADE/PROTECT, reconciles RESTRICT against native cascade closure, reads
  concrete parents and auto-created through rows, preserves root-inclusive trees and numeric summaries,
  and explicitly marks unknown on_delete/private/root model-delete effects incomplete even when empty.
- The confirmed write path uses `_DeleteCollector` only for exact Django `Model.delete`. It dispatches
  native handlers by identity, stops at native PROTECT, maintains a sticky executable-callback flag,
  never aggregates custom failures, and inherits Django's SQL executor, signals, origin and PK clearing.
- Actual OrderedModel Author and polymorphic Car methods accept `using`, run once, retain sibling reorder
  and parent-row semantics, and propagate actual stale PROTECT/RESTRICT errors. Their ordinary previews
  show the independent incomplete warning. Existing Author form-control goldens remain unchanged.
- Pinned alias selection receives the saved instance hint and remains available after PK clearing.
  Direct processing pins before mutation in both atomic modes; selection, atomic entry, success hook and
  on_commit share that alias. Missing/unsaved pre-object access raises `ImproperlyConfigured`.
- Independent incomplete notices render with details disabled, hidden labels and business/native protection;
  partial summaries retain integer counts. Existing full-page/modal response contracts remain intact.
- All legacy classifier, unsafe collector and no-using spy assumptions were migrated before the first
  combined deletion-file gate. Raw protection still supplies blocking before display permission filtering.
