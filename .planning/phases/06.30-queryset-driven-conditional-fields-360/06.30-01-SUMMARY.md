# Phase 06.30 Plan 01: Native queryset conditional groups Summary

**Native model-choice selectors activate groups from validated categories, clear inactive persisted values, and report offered-option coverage safely during rendering.**

## Accomplishments

- Exported `QuerysetConditions(controller, *, conditional_key, keys, allow_unmatched=False)` with immutable declarations and internal `_QuerysetToggle` memberships. The initial admission validator accepts stock ModelChoiceField/Select without evaluating choices.
- Extended the existing group-validation and final-clean mapping paths. A selected object is resolved once per source during clean; unknown strict selections produce `unmatched_category` field errors. Missing, invalid and blank selectors never fall back to raw category data.
- The HTTP tracer extracts actual rendered option keys, saves active data, switches to an explicit no-fields category, saves again, refreshes the database, and GETs the cleared form. Other truthy model-object categories do not activate unrelated groups.
- Offered projection reads only the current queryset, category and `str(field.prepare_value(obj))`. Tests pin native UUID/text option equality, escaped hostile metadata, no extra label calls, one shared projection per render, new-context re-evaluation, and queryset replacement.
- Strict unbound rendering raises `QuerysetConditionCoverageError`; bound rendering catches only that exception and emits escaped visible diagnostics outside hidden groups. Existing field/nonfield errors, valid siblings and untouched extra rows remain renderable.
- All-no-fields declarations use `ConditionalGroup(source.when(), fields=[], required=[])` plus an explicit `ToggleGroup(source.when())` in the base helper or ordinary `InlineFormSet.get_helper_layout_fields()`. The controller stays outside the guard. Construction is query-free; successful guard rendering emits no conditional container. The source docstring and executable recipes explain this complete integration and why omitting the guard omits render coverage.
