## Accomplishments

- Categories accept nonempty exact strings, integers excluding booleans, and UUIDs. Duplicate serialized keys, unsupported values and indirect attribute syntax fail deterministically. Missing/empty/callable categories remain unmatched; methods are never invoked.
- Native integer/text/UUID primary keys and concrete unique scalar `to_field_name` are admitted from model metadata. Nonunique, relation, lookup-path, composite and unsupported scalar identities are rejected without queries. Label-only subclasses retain native selection; custom iterators, manually replaced field/widget choices, overridden selection hooks and custom/multiple widgets fail admission.
- Equivalent immutable sources compare by declaration and share form-local category/projection work. Conflicting sources fail for either order. Existing mixed ValueToggle/queryset group ownership checks prevent overlapping fields, controlled controllers and required fields outside their group.
- E313 keeps its ID and now explains both static choices and native unique ModelChoiceField keys. Base and inline check traversal is tested with hostile queryset evaluation and form-construction sentinels. Missing request-added controllers retain E311; request-added controlled fields are deferred to runtime inspection.
- Whole ConditionalFormSet activation rejects queryset memberships for skip and purge; passing the source itself fails the existing ToggleSource type boundary. Checkbox/static-choice regressions and public exports pass.
- Final inherited None/replacement/removed mappings, fresh category changes, restricted/forged/stale selections, required/optional blanks, disabled controllers and controlled fields, shared membership, permissive-controller independence, invalid inactive values and explicit falsy clearing are covered. Native uniqueness and a real model CheckConstraint still reject invalid final states.
- Real FormSetMixin create/update POSTs prove valid independent rows save correctly and invalid retained rows issue zero INSERT/UPDATE/DELETE statements. Forged foreign-parent row identities are rejected. Existing unchanged rows set the conditional save marker and save exactly once; empty extras remain unsaved and deleted rows can carry unmatched selections.

The projection adds exactly one evaluation per row/controller/render, independent of offered option count; no cross-row or SQL-string cache exists.
