# Phase 06.30 Plan 03: Compact rendering and conditional lifecycle Summary

**Compact queryset cells now retain geometry and row-owned membership while automatic coverage guards validate offered options; the JS lifecycle preserves values, disables inactive inputs and recovers focus.**

## Accomplishments

- Added private `_QuerysetToggleCell`, preserving the existing crispy `Div`, labels, help, spans and field errors while attaching group/queryset/disable-only markers to that same cell.
- Compact helpers discover sources structurally, deduplicate by controller, and prepend empty coverage guards outside the row grid. All-no-fields declarations therefore enforce strict offered-option coverage too. Bound redisplay exposes escaped diagnostics and retains unrelated errors.
- Schema, projection and helper construction remain free of option queries, including detached schemas for empty formsets. Identity, parent, order, deletion and management controls remain outside conditional cells.
- Queryset-marked empty arrays mean inactive; malformed static arrays retain their previous rejection behavior. Compact cells keep their original display while existing ownership reconciliation disables inputs without clearing browser values.
- Newly disabled focused compact controls recover to their usable controller or existing form fallback; unrelated focus is preserved. Tests cover two unusual exact prefixes, distinct owning forms, parent nesting, independently disabled controls, shared option membership, blank/no-fields/unknown selections, native FormData, reset/cancelled reset, inserted rows and modal disposal/reuse.
