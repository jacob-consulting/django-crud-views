### Exact class selection and intentional suppression

**Source:** `src/crud_views/lib/button_classes.py:201–223`; applies to widget and rendering tests:


```python
classes = get_button_classes()
key = f"{location}:{slot}"
if mode and f"{key}:{mode}" in classes:
    key = f"{key}:{mode}"
value = classes.get(key)
return value if isinstance(value, str) else ""
```

Choose `workflow:transition-<variant>` only for supported variants; otherwise use `get_button_class("form", "submit", "label")`, including when an icon is present. Never apply `resolved_class or fallback`: empty/null overrides deliberately suppress styling.
