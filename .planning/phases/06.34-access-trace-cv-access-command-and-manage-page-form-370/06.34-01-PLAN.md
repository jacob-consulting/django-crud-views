<interfaces>
Freeze the version-1 public scalar projection before other plans consume it. AccessTrace.to_dict() emits exactly: version=1, path, route, view, user, outcome, decided_by, plan, steps, untraced. User fields: pk (string or null), username (string or null), active (bool), anonymous (bool). Outcome codes: allowed, denied, not_found, login_redirect, error, no_such_route. decided_by is a 1-based steps.n or null. Every AccessStep serializes n, kind, viewset, object, key, permission, group, provider, source, result, how, message, exception, counts; absent values are null. object is {model,pk}, with pk stringified without calling object.__str__/repr; exception is {class,message}; counts is {visible,total}, with total null for Resource. Results: passed, denied, not_found, skipped, not_reached, not_evaluated, error. Kind codes include route, login_middleware, validation, actor_admission, ancestor_lookup, ancestor_gate, own_permission, object_lookup, object_grant, list_filter, action_state, manage_gate, custom_gate, limitation. Plan entries are {kind,viewset,object,key,permission,group,provider,source}; unreached full permission may be null when expanding it would perform a protected read. Stable codes are separate from translated messages. untraced always contains "other middleware and URL decorators are not traced". Result never stores users, model instances, querysets, requests, responses or tracebacks. Private recorder state is discarded after assembly.
</interfaces>

Private observation additions: `AccessRecorder.capture_login_response(owner, response)` retains actual login response identity until assembly, then clears it; no response enters the public scalar projection. Classmethod gate reporting uses one fresh opaque owner token per invocation, retained privately for that recorder's lifetime. It never deduplicates separate classmethod invocations by class or actor PK. Instance gate reports retain the view instance as owner, deduplicating repeated identical object/state reports within that instance only. Neither mechanism changes gate signatures or adds an ambient request-scope framework.

Translation contract (A-07): keep access_trace.py importable before Django settings/apps exist, with standard-library module imports only; translate presentation centrally in the runner/command, using direct gettext-family calls with literal msgids/context and named `%(name)s` interpolation after translation. Use ngettext/npgettext for plural choice, formatting numeric display values through named string substitutions. No computed/f-string/format-template msgids. Plan 09 expands and tests the extractor for singular/plural/contextual and lazy variants plus imported Django translation-module calls; stable codes remain untranslated.
