# Phase 06.34 Plan 06: Access command Summary

**cv_access now formats the shared trace as translated text or versioned JSON, with fixed terminal colors and proven real exit statuses.**

## Accomplishments

- `Command.add_arguments` accepts path plus username/PK or `--anonymous`, and `--as-json`, while retaining Django's color controls. `handle` uses only `resolve_trace_user` and one `trace_access` call. Username-first collision precedence, inactive identity and full-URL path extraction follow the shared implementation. Automatic system checks are disabled so routing configuration errors reach the structured trace. The web exposure setting has no effect.
- `_format_text` presents normalized path, route, full view class, actor, declared plan, numbered observations, permission/group/provider/source/object identity, grant attribution, counts, exceptions, limitations and deciding step. Allowed output ends with “may open the page” and the handler-phase boundary. Unknown actors and text no-route diagnostics stay on one line; `_text` escapes control characters in diagnostic data.
- `_format_json` serializes exactly `AccessTrace.to_dict()` once. Actual no-route and error results retain the same version-1 document. Unknown actors and invalid calls produce no trace document. `handle` returns no truthy value; mapped nonzero outcomes use SystemExit after output. Allowed exits 0; denied/not_found/login_redirect exit 1; no_such_route/error and command actor/usage errors exit 2. Conflicting Django color flags retain Django's native CommandError and exit 1, as explicitly required by Task 2.
- `_style` uses fixed Django termcolors and one explicit dim wrapper; it ignores DJANGO_COLORS role customization. `_color_json` wraps complete serialized keys and result/outcome string tokens without changing escapes. Default pipes and `--no-color` are plain; terminal output and `--force-color` use fixed green/red/yellow/dim, with cyan JSON keys. Message text equal to a result code is not accidentally styled.
- The process fixture configures the existing test project against an explicitly supplied parent-owned temporary SQLite file, seeds three users and one object, and registers four bounded routes. Real handlers raise if called. Real subprocess and PTY tests exercise all six outcomes, errors, help, identity collisions, anonymous paths, flags, JSON framing and escaped Unicode/control data. Parent fixtures remove the temporary directories; processes and PTY descriptors are closed, including timeout cleanup.
