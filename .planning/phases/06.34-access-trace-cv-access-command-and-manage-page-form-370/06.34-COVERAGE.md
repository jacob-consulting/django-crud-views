## Boundary decisions and probes

- D-18 governs sequencing: first task is the real authorization-to-trace tracer; command follows recorder/fidelity, form follows command. No premature UI slice.
- Inactive/plain and Guardian-list shorthand yields to actual gates under D-11/D-20; no policy changes.
- POST-only whitelist receives GET only on the diagnostic instance, with a visible method/handler limitation; custom method-sensitive dispatch is an explicit unsupported error. Real GET parity uses GET-capable family representatives.
- Fixed synthetic origin is http://localhost; a bounded HttpRequest subclass supplies get_host. No supplied URL host is trusted and no global ALLOWED_HOSTS mutation occurs.
- Non-login redirect, early success without stub, 405/5xx or nonresponse yields error. Only observed real middleware/Django access-mixin login responses count as login redirect.
- Default savepoint always rolls back; exception normalization occurs outside it. Memory session/messages never save to a configured backend. Other DB/external/cache effects are documented limits.
- Mockup hierarchy is adopted; its object label is excluded per D-05. Both web forms retain username/PK collision precedence, with no anonymous UI control.
- Requirement-ID edge probe: SKIPPED — phase requirements are prose and no formal phase IDs exist. Frontmatter contains roadmap prose; D-IDs are decision traceability, not invented requirement IDs.
- Assumption-delta detector: detected=true (optional recorder, another actor, parameterized builder). Recorded no-change decision in 01: authorization observation is the noun; explicit actor builder is already the correct abstraction. No new identity model or approval needed.
- Schema-push detection: no listed ORM/schema patterns or schema mutation in scope. No schema push.
- Research/discovery: supplied current research and exact source patterns suffice; no new dependency choice. Graph query exists=false. API index zero/stale is not authoritative.
- API-coverage detector ran over all final plans plus the roadmap phase section: detected=false, signals=[], exit 1 (the detector's normal negative verdict). No external service is integrated; Resource loaders read existing application sources under D-10. No API matrix is required.
- Excluded by approved scope: configuration dump #371, Resource manage pages #372, impersonation, full middleware/decorator execution, workflow transition permission enumeration, general bulk tracing. No excluded item is planned.
