## Shared Patterns

- **Authorization owns decisions:** ancestor, own model/state, Guardian, manage and Resource owners above
  report already-computed facts. The recorder must not return policy decisions, terminate dispatch, count
  querysets or add alternate checks. No behavior/query/order change when absent or enabled on ordinary requests.
- **Plan versus execution:** reuse pure metadata helpers and own requirement descriptions; preserve validation,
  actor, lookup, routing guard and gate order. An unreached requirement stays unreached; metadata preparation
  must not mask an earlier real login/custom outcome.
- **Viewer and actor:** host manage access stays tied to its real request.user; tracing uses a freshly loaded
  project user (including inactive) or fresh anonymous actor. Both forms and CLI share username-first lookup.
