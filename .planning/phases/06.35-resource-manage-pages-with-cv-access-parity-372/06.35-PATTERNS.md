## Shared Patterns

- **Authorization before diagnostics:** A1 ancestor-first dispatch, independent developer gate, existing nested database validation and A4 denial spies. Resources remain leaves without Guardian item grants.
- **One permission owner:** A2 explicit map feeds A1 unchanged cell contract and A3 badge selection. None/empty maps produce no permission columns, not public-access claims.
- **Static inspection:** no built-in item/list loader calls for initial configuration, permission matrix, hierarchy, checks or routes. Parent-model/auth reads remain legitimate. Add no cache, hook sandbox or arbitrary override interception.
- **Trace compatibility:** preserve version 1, object identity's existing `model` key, ordered steps, deciding step, counts, errors and limitations. Actual core/none providers remain distinct from the resource badge. Existing exits remain allowed=0; denied/not_found/login_redirect=1; no_such_route/error=2.
- **Escaped localized output:** retain gettext/translate/blocktranslate, paired German PO/MO, scalar errors and identity-only trace serialization. Never stringify Resource contents for diagnostics or imply rollback undoes external I/O.
- **Delivery/testing:** existing normal/recorder contracts and multicore broad runs apply during execution. This map ran no application tests and adds no acceptance claim beyond research's stated probes.
