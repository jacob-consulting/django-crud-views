No unrestricted Any/report dictionary. Known dynamic maps use string keys and concrete value models; only ValueRecord.value contains bounded recursive JSON. Preserve additive-field consumer tolerance; do not publish closed additionalProperties promises incompatible with documented additive fields.

Envelope: version Literal[1], kind catalogue/inspection, status complete/partial/failed, selection {viewset,view,user: nullable strings}, data typed payload/null, errors list[ReportError]. Error fields: code (invalid_arguments, unknown_viewset, unknown_view, unknown_user, collection_failed, output_validation_failed), section nullable section key, message string, exception_class nullable string, location list[string|integer]. Section fields: status ok/error/not_applicable, data typed/null, errors list[integer] indexing the envelope errors. Enforce valid references and status/data combinations; complete has no collection errors, partial has useful surviving data plus errors, failed has no usable data plus errors. Check findings do not change completeness.

CatalogueData.entries items have name, kind model/guardian/resource, backing_class, parent nullable name, views ordered string keys.
InspectionData has identity plus facts, presentation, views, routes, hierarchy, ancestor_policy, permissions, checks, guardian, each a concrete Section payload. Identity has name, kind, backing_class, parent. Add scope=viewset to all ViewSet-wide payloads and scope=selected_view or viewset to views/routes containers; selected_view nullable key. Preserve these explicit scopes in text.

ValueRecord: kind native/class_path/unsupported/not_declared, value bounded JSON or null, python_type nullable dotted type, normalizations list[{path: list[string|integer], python_type: string}]. Class-path values are strings with kind=class_path. A native null is distinct from all other kinds. SourceRecord: code default/set/inherited/viewset/global_setting/model_meta/resource_meta/fixed/not_declared/effective, setting nullable string, declaring_class nullable dotted path. ConfigEntry: key, value, source, is_default strict bool, unknown nullable bool, declared_value nullable ValueRecord; explicit optional icon, type, is_button, empty_buttons, points_to, label fields retain existing owned button/display facts. ConfigGroup: key,label,entries,default_count. PresentationData: sections,default_count,set_count. Facts is an ordered entries container.

ViewRow mirrors every existing public inventory field: key, route_name, route, route_error, class_path, requirement {kind,value,ancestor_applies}, permission, parent_requirement {key,permission}, requirement_metadata_error, guardian_policy nullable typed ViewPolicy, parent_only_requirement nullable bool, sections. HierarchyData: parents,children,route_error; HierarchyItem: name,model,resource,route_name,route,route_error,url.
