### Discovery failure must not become empty success

**Source:** `src/crud_views/checks.py:185–195`; **apply to:** command and optional loader extraction.

```python
pending, seen = [get_resolver()], set()
try:
    while pending:
        resolver = pending.pop()
        if id(resolver) in seen:
            continue
        seen.add(id(resolver))
        pending.extend(pattern for pattern in resolver.url_patterns if isinstance(pattern, URLResolver))
except Exception:
    return False
return True
```

Reuse the traversal with an explicit command failure on incomplete loading, or extract a throwing helper while keeping this boolean readiness wrapper compatible. Snapshot registry entries under the lock, as `src/crud_views/lib/viewset/__init__.py:229–232` does; release before diagnostics. Schema branches before discovery; catalogue does not collect permissions or checks.
