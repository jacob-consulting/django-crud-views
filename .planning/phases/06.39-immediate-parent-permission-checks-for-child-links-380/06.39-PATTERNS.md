### `src/crud_views/lib/view/base.py` (controller, request-response)

**Analog:** its existing destination-owned classmethod adapter, lines 523–530:

```python

@classmethod
def _cv_child_link_has_access(cls, user, parent_obj) -> bool:
```

### `src/crud_views_guardian/lib/mixins.py` (middleware, request-response)

**Analog:** `GuardianQuerysetMixin._cv_child_link_has_access`, lines 296–308:

```python
@classmethod
def _cv_child_link_has_access(cls, user, parent_obj):
    if not cls.cv_viewset.has_parent:
        return super()._cv_child_link_has_access(user, parent_obj)
    if not user.is_authenticated or _guardian_inactive_actor(user):
        return False
    access = super()._cv_child_link_has_access(user, parent_obj)
    if not access:
        return access
    # Standalone queryset compositions never checked the parent for their links (bounded migration).
    if not issubclass(cls, GuardianParentPermissionMixin):
        return access
    return _immediate_parent_access(cls, user, parent_obj)
```

This is the closest cooperative-inheritance pattern, but its delegation/last gate must change together when core
acquires the gate. Keep nested actor admission first. Preserve standalone queryset-only own/custom access without
reaching the new core parent gate. Shipped collection compositions should delegate to the common gate once and
must lose their former second helper call. Keep top-level delegation. Do not remove the module's helper import
without checking its other existing uses.

**Validation/own-access pattern:** lines 287–294 reject inactive actors, call `_check_nested_auth`, and check the
configured permission vocabulary. Preserve this path rather than substituting child-row existence checks.

Leave these gates in place. Context evaluates state before access; card evaluates access before state. Ordinary

### Authorization, validation and failures

Own denial short-circuits parent permission work. Guardian nested actor denial precedes custom access. Reuse
`_immediate_parent_access` for the supplied object, destination operation, parent provider/fallback and validation;
do not fetch farther ancestors or catch `ImproperlyConfigured`. Preserve the explicit queryset-only exception.
There is no new logging, transaction, cache or response-envelope pattern to introduce.

the child-link module; broad execution and supported Django-series checks use multicore pytest. This pattern-map
task ran no application tests and makes no changed-code cost or pass claim.
