## Accomplishments

- The private resolver recognizes exact supported standard form/model pairs and native persistence hooks. Nullable text/scalars/FK clear to None, blank non-null text to an empty string, non-null Boolean to False, FileField/ImageField to False and M2M to an empty collection. Plain CharField uses empty_value and plain MultipleChoiceField uses an empty list. Explicit dictionary membership preserves falsy overrides. Custom/unsupported shapes raise a descriptive ImproperlyConfigured naming the toggle/group and field.
- Server-disabled fields are excluded before required disarming, suppression, automatic clearing and explicit overrides. Native validation errors remain observable. Active groups retain ordinary behavior; inherited nonfield errors, model clean and actual schema-backed uniqueness still block persistence.
- Cooperative _post_clean applies scalar/file values with save_form_data before inherited model construction/validation, preserving omitted default-field clearing. M2M remains in Django's save_m2m path.
- A private effective-change signal allows unchanged existing inline rows to reach the existing commit=False → instance.save → save_m2m sequence. It compares pre-mutation state, resets during full_clean and preserves the original comparison through revalidation. XFormSet consumes it only for non-adding, error-free instances; blank extras and already-empty/native-no-change/disabled controls are not forced to save.
- ConditionalPersistenceRecord is a test-only schema model with a real parent FK, representative scalars, nullable FK, unique text, FileField, ImageField and M2M. No product schema migration or unrelated application-model definition changed.
