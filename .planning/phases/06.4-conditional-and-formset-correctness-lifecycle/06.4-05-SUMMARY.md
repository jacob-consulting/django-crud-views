**Conditional controls compose nested and independent disables, preserve entries, synchronize cancellable native resets after defaults, and recover focus only when hiding strands it.**

## Accomplishments

- Per-form observation and per-control independent baselines compose all bound ancestors in either nesting order. Same-value external disabled=true writes are observed, pending records are drained before synchronous updates, and temporary library writes cannot become baseline. Reinitialization includes new descendants without losing existing ownership.
- Inputs, selects, textareas and native buttons share ownership rules. Custom Add/Delete/Reorder buttons disable while inactive; values and file-list identity survive off/on. All four management suffixes receive no conditional owner, while independent disables and native disabled fieldsets retain their native effect on FormData.
- Native reset schedules one form-local macrotask, checks defaultPrevented there, and lets the browser restore values/defaultChecked. Later form/document listeners can cancel without any reset synchronization. No row, total or value is manually rebuilt or cleared.
- Focus moves only for an actual transition hiding an active descendant. It tries a usable controlling checkbox and nearest bound ancestor, then the visible owning form with temporary tabindex. Candidates check geometry, connection, hidden/inert/aria-hidden/disabled/aria-disabled ancestors and actual focus success. Hidden initial modal content receives no early focus, and existing tabindex remains intact.
- Ready-state startup supports late scripts. Existing page/modal/row-added events and explicit roots use the same initializer. Modal unload drains observations, removes conditional/reset handlers and releases temporary disables; retained content can be reinitialized with fresh independent state. Existing modal events, payloads and widget teardown dispatch order are unchanged.
