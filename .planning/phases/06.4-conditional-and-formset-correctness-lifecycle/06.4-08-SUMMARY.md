## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Newly added nested formsets lost the editor endpoint inside modals.**
- **Found during:** 08-02 real modal outer-Add followed by nested second-child Add.
- **Issue:** `FormSet.template()` left descendant declaration `path` unset. jQuery therefore requested the modal host URL and received full-page HTML instead of editor JSON. Full-page fixtures masked the missing path because their current URL was already the editor.
- **Fix:** View-backed template generation assigns the authorized request path before recursive rendering. Request keys, response keys, declaration indices, ancestry/permission gates and standalone no-view behavior remain intact.
- **Files:** `src/crud_views/lib/formsets/formsets.py`, `tests/test1/test_fragment_authorization.py`.
- **Verification:** Accepted focused RED; 89 tests on each of three Django series; actual outer/nested modal Add and persisted 204 outcomes in stock/native Chromium.
- **Commits:** `5650b57`, `61011bb`.

No architectural decision, authentication gate, package install or unrelated production repair was required.
