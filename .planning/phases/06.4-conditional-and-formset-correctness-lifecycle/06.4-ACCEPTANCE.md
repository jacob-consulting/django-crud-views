## Persistence, authority and public-surface bounds

The supported matrix remains the precise one in [conditional.md](../../../docs/reference/conditional.md):
standard nullable scalar/FK values use native null where supported; non-null blank text uses its supported empty
string, Boolean uses false, standard FileField/ImageField references use false, and standard M2M/multiple-choice
collections use empty collections. Explicit `empty_values` retain native meaning (notably FileField None is
no-change), and trusted disabled fields retain their original authority. Unknown/custom/JSON/typed/multivalue or
unsupported non-null shapes require explicit configuration. Native form/model/uniqueness/database invariants remain.

Actual unchanged `XFormSet.save` cases refresh DB state, assert save-call counts and retain stored bytes with
zero storage-delete calls. Real received multipart FileField bytes are discarded off-state without a storage
write. **ImageField evidence is reference-only:** the disabled-image fixture uses native initial=None/no-change;
image-byte decoding, dimension hooks and nonempty disabled-image initial validation are unclaimed. No Pillow
installation or required test skip was introduced.

Active policy failures invoke zero main/sibling/nested save hooks before entering the write traversal. Existing
routed atomic rollback remains a later-failure backstop. Inactive first-level formsets retain default skip and
explicit managed-queryset aggregate purge; that separately authorized purge is not narrowed to per-row delete
permissions or active edit-only policy. Nested ConditionalFormSet remains unsupported through E310.

[PUBLIC-SURFACE](06.4-PUBLIC-SURFACE.md) hands off the root initializers, exact bound marker/context semantics,
native control hooks, E312/W320 migration, error codes and template/JSON/event projections. Render-tree/controller
constructors, resolver/ownership state and save methods stay internal. A8's runtime `commit=False` public/internal
classification remains for Phase 7. No jQuery port (#210), A25 enhancement, arbitrary custom theme/backend/field
certification or broader Guardian #286/slug/custom-text protocol guarantee is added.
