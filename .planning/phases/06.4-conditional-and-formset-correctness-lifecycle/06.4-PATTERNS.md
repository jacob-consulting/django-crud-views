## Pattern Assignments

### Conditional rendering and clearing

Applies to conditional Python modules, checks, group template and conditional tests.

**Imports and rendering analog:** `src/crud_views/lib/conditional/layout.py:3–4,25–35`:

```python
from crispy_forms.layout import Layout, LayoutObject
from django.template.loader import render_to_string

def render(self, form, context, **kwargs):
    inner_html = self.inner.render(form, context, **kwargs)
    context.update(
        {
            "cv_toggle_field": self.toggle_field,
            "cv_toggle_css": self.css_class or "",
            "cv_toggle_legend": self.legend or "",
            "cv_toggle_inner": inner_html,
        }
    )
    return render_to_string(self.template, context.flatten())
```

Copy the renderer/context shape, **replace the unbound field name** with the bound-name contract. Formset wrappers also need the owning form's bound name; `XFormSet.cv_toggle_field` currently returns the declaration name (`render_tree.py:195–198`). Changing the crispy wrapper alone leaves A1 incomplete.

**Cooperative validation analog:** `src/crud_views/lib/conditional/group.py:62–69`:

```python
def clean(self):
    cleaned = super().clean()
    for group in self.cv_conditional_groups:
        if group.is_on(self):
            self._cv_enforce_required(group, cleaned)
        else:
            self._cv_clear_group(group, cleaned)
    return cleaned
```

Preserve inherited clean/model validation. Current `empty_value_for` at lines 36–37 and clearing at 78–84 are repair targets, not safe resolver analogs. Server `Field.disabled` must take precedence before suppression and explicit overrides. Use the RESEARCH clearing matrix and model-construction ordering; this checkout has no already-correct general resolver to copy. Checks and runtime must share the resolver without creating arbitrary request-dependent forms at startup. Follow existing `checks.py` E310/E311/W320/W321 conventions and verify new IDs before allocation.

## Shared Patterns

- **Authority:** Django gates and authorized querysets own writes. DOM capability guards never replace D-11/D-12 validation.
- **Validation/error order:** preserve cooperative inherited validation and eager two-pass traversal; configuration errors are programming errors, not user field errors. Keep custom clean hooks and M2M persistence.
- **Lifecycle:** page ready state, modal loaded and outer row added converge on one root initializer; unresolved binding remains retryable. Include root itself and owning forms, preserve values and independent disabled reasons.
- **Documentation:** extend existing reference sections and pair each Breaking entry in `CHANGELOG.md` with `docs/migrating-1.0.md`; inventory new public initializer names for Phase 7. Template projection does not make `XForm`/`XFormSet` persistence APIs public.
- **Dataflow:** bound server name → template marker → owning-form exact checkbox match → composed client state; POST → conditional values → model validation → active formset policy → existing routed transaction. Fragment coordinates → authorization/ancestry → declaration index → rendered prefixes → management totals → POST.
