| Row JSON: `key`, `prefix`, `prefix_key`, `formset_prefix`, `pk` | Same complete runtime comparisons |

Formset JSON `pk` is `FormSet.PK.value`: integer regex `\d+` or UUID regex
`[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}`.
Row JSON `pk` retains `PK.INT` / `PK.UUID`. Neither value is the request's actual parent identity.
Exact JSON examples and row coordinates are executable comparison inputs in the reference page.
Row eligibility follows the original bound row index through moves/insertion, never display order. Native DELETE
absence is supported; it neither grants deletion nor blocks permitted Add/Move/submission.
