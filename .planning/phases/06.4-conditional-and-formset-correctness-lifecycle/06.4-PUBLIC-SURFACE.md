Formset JSON `pk` is `FormSet.PK.value`: integer regex `\d+` or UUID regex
`[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}`.
Row JSON `pk` retains `PK.INT` / `PK.UUID`. Neither value is the request's actual parent identity.
Exact JSON examples and row coordinates are executable comparison inputs in the reference page.

and modal `onHidden` completion/focus ownership. jQuery is still required for formsets. A8 final dynamic-row reset
policy, A25, jQuery removal/port, arbitrary custom field/backend/theme certification and broader primary-key/Guardian
protocols remain outside this phase. Image uploads retain Django's existing consuming-application Pillow prerequisite;
reference-only evidence must never be presented as image upload decoding coverage.

this inventory records neither completed stability classification nor human approval.
