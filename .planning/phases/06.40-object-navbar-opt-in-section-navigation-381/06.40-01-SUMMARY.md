- Added the three public declarations/mixin in one bounded module, one context-taking tag and the initial layout-B wrapper. Request data never enters shared declarations; absent/None/falsy data makes the tag emit an empty string. Modal requests receive None.
- Real request tests cover owner detail/update/notes/unlisted views, child list/detail/create/update/custom views, grandchildren and a fourth-level edit beneath a nested owner. Structural identity overrides extra kwargs.
- Owner default labels receive a ViewContext bound to the resolved navbar owner, retaining the rendering view. Tests cover escaping, literal entities, markup-bearing safe strings, lazy labels and parsed visible text.
- Added viewset.E280 (declaration), E281 (attachment), E282 (destination), E283 (duplicate), E284 (wrapper template). Checks preserve super checks, perform zero queries and never call access/state hooks.
- URLconf preflight occurs before registry iteration. Import-free readiness uses cached url_patterns presence, including empty patterns. Genuine cold imports register invalid views on both existing and new ViewSets and report every late diagnostic on the first completed pass; failed and reentrant imports preserve local errors without retrying during iteration.
