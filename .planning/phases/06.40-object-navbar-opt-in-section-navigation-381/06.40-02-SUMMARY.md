# Phase 06.40 Plan 02: Lazy accessible navbar templates Summary

**Three guarded templates share one lazy request result and render plain owner identity plus ordered, accessible section links with a shipped German landmark translation.**

## Accomplishments

- The wrapper includes identity first and links second. Each template independently guards `cv_navbar` before emitting any bytes; absent, all-hidden and modal bars leave no HTML or whitespace. Relative includes preserve normal theme template-loader overrides. Per-bar wrappers retain the same named context and can reuse both leaves.
- Tests cover global wrapper, identity-only, items-only, custom per-bar and split placement. Repeated `get_context_data`, shallow template-context copies, `new`, `flatten` and isolated `include ... only` preserve wrapper identity and one build. Separate requests/users have distinct results. Context-only and actual HTTP omitted/modal responses perform zero builder/access/state calls.
- Identity is ordinary text with decorative existing-renderer icons. Items own an independently named nav landmark, a list of ordinary anchors and at most one `aria-current="true"`. Descendant Orders links remain clickable. Hidden first/middle/current items leave no gaps or fallback active selection; zero/one/many and missing-icon states retain their specified behavior.
- Scoped `nav-pills`, `flex-wrap`, `gap-1`, `mw-100` and `text-break` utilities preserve full long captions/labels without a global stylesheet, script, loader or retry UI. Real browser wrapping remains the later plan's acceptance gate.
- German source/compiled catalogs add only `Sections for %(object)s` → `Abschnitte für %(object)s`. Literal German assertions exercise the actual items template. Parsed captions, link text and accessible attributes cover ampersands, apostrophes, quotes, literal entities, percentages and SafeString markup with no injected nodes/attributes or double escaping.
