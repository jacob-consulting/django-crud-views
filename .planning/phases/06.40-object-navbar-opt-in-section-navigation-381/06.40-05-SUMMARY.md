## Accomplishments

- Added app-owned Order, Item and Address models, forms, tables, all CRUD routes and a normal second migration. Parent attributes explicitly map to `customer`/`order`; every nested ViewSet declares `AncestorPolicy(cascade=True)`. Tenant remains the only Guardian object-grant boundary. No core authorization or navbar-builder behavior changed.
- Customer's declaration has exactly Details, Notes, Orders and Addresses. Order list/detail/create/update and Item pages reuse its identity and URLs. Order delete deliberately omits the mixin, proving attachment is independent of ancestry. Unequal PK tests check actual public URLs, correct parent assignment despite injected parent fields, manager CRUD, cross-Tenant requests in both directions, and unchanged business rows after denied POSTs.
- Added transactional, repeatable app-local seed data with distinct PKs, separate manager tenants, Customer notes and an Alice Customer with zero Orders. Alice/Bob receive business-model CRUD and only their Tenant's view/change object grants; Charlie receives Customer/Order/Item view plus Alice Tenant view. No business-record object grants are required. Existing unrelated user permissions survive reseeding; developer's explicit model list and last-account position remain intact.
- Added Charlie to account creation and seed-command help. Shared translated notices/catalogs remain unchanged. The owned introduction renders literal `alice/alice`, `bob/bob`, `charlie/charlie` and the existing login URL. Tests log in through that actual route and exercise each named user's endpoints, successful writes, denials and empty Orders.
- Registered the app last in the UI feature group. The standalone authenticated introduction uses the existing BreadcrumbMixin, about panel, snippets and an ordinary empty message. Its Customer choices come from strict Guardian Tenant filtering plus Customer view permission; arbitrary authorized usernames work, and global Tenant permission alone reveals no choices. It renders 200 for an authenticated superuser with no seed data.
- Added one whitespace-neutral example-owned `cv_navbar` block immediately after breadcrumbs and before the existing card. Parsed HTML checks identity/items/header ordering and three/four links.
