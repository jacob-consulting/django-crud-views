## Accomplishments

- Fieldless actions can skip confirmation; mixed selections fall back to an unbound review before any write. Forms with declared fields still require input and execute on one valid submission.
- All-blocked requests use a private form with only the stock Cancel control. Its URL follows origin, cancel target and success fallback without changing shared crispy form code or ordinary review cancellation behavior.
- The shared warning alert precedes the counted eligible list and form. Both public snippets are overridable independently of hidden selection transport; names and reasons remain escaped, labels are plain text, and unavailable IDs have no visible identifying label.
- Fresh execute checks preserve exclusions carried by the request, reject newly blocked candidates without mutation, and allow a now-eligible candidate to execute directly under the documented stateless contract.
- Execution tests pin one item check per request, the transaction boundary, two nested-write guards, stock public hook order, the bypass of `cv_form_valid_process`, rollback and on-commit behavior, and exact success messages.
- Added application recipes for protected deletion and a locked re-read that checks both row count and fresh business eligibility before writing. No library locking or public API was added for these recipes.
