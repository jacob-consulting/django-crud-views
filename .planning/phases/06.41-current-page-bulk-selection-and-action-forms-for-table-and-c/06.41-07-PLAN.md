<objective>
Validate bulk configuration at startup: nine core checks on the two classes (D-02, D-08, D-26) and one Guardian
warning (issue section 7.7), with every already existing check reused instead of duplicated.

Purpose: a developer who misconfigures a source or a destination learns it from `manage.py check`, not from a
broken page; a Guardian project is warned when a bulk action could be more permissive than the single-record
views beside it.

Output: `checks()` on `BulkSelectionMixin` and `BulkFormViewPermissionRequired`, the Guardian check with its
German translation, `tests/test1/test_bulk_checks.py`, and the German catalog entries for every core string of
the feature with `tests/test1/test_bulk_i18n.py`.

Requirements are intentionally empty: the phase has no requirement IDs; issue #387 and CONTEXT D-01 to D-31 are
the contract. The spec-less probe fallback was visibly skipped for the same reason.
</objective>
