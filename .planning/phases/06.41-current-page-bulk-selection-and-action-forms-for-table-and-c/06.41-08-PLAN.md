<objective>
Prove that a bulk destination returns where D-25 to D-27 say: Cancel, the warning redirect and a plain GET lead
back to the exact source page, from tables and cards alike, and success goes where the destination declares. A
forged return token cannot redirect off the site.

Purpose: the library adds no return protocol of its own for bulk actions; it relies on the origin mechanism the
update and delete views already use. This plan turns that reliance into regression tests before the system
checks and the guide describe it.

Output: `tests/test1/test_bulk_return.py`, one filter-enabled bulk test ViewSet, and any defect fix the tests
require in `crud_views.lib.bulk`.

Requirements are intentionally empty: the phase has no requirement IDs; issue #387 and CONTEXT D-01 to D-33 are
the contract. The spec-less probe fallback was visibly skipped for the same reason.
</objective>
