# Native checkbox Enter regression found during plan 13

At source revision `3073fa4a`, the stock toolbar starts with `<button type="submit" disabled hidden></button>`.
On cached Chromium 159.0.8154.6 and 149.0.7827.55, pressing Enter on a focused external selection checkbox skips
that disabled button and activates the first enabled action. With JavaScript off, the example table sends a native
POST to `/bulk-selection/document/bulk-delete/` with `cv_bulk_stage=review`; an empty selection then redirects to
`?cv_from_restore=1`. This violates plan 07's no-navigation acceptance even though the destination safely rejects
the empty selection. The browser test failed before selecting or mutating any document.

The isolated reproduction uses a form with the hidden disabled submit, an explicit Delete submit button, and an
external checkbox associated with `form=id`. It reproduces with a visible disabled default too, so CSS visibility
does not explain the defect. Both cached Chromium versions show the same result. The Playwright connector itself
could not initialize because its configured Chrome executable `/opt/google/chrome/chrome` is absent; the local
runner uses already-cached Playwright 1.64.1 and Chromium, with no download or installation.

Replacing only the sentinel's `disabled` attribute with `formmethod="dialog"` prevents a navigation in both
JavaScript modes in the isolated reproduction; an explicit click on Delete still reaches its configured URL.
The [HTML form submission algorithm](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#form-submission-algorithm)
returns when the chosen method is dialog and the form has no dialog ancestor. This is bounded to the existing
full-page toolbar contract: no JavaScript event handler, new control, selection recovery, or server machinery.
Bulk modal flows are already unsupported. The template comment must explain the otherwise surprising attribute.

The initial full Django 5.2 suite ran against the pre-fix template. Its receipt remains useful regression evidence,
but a post-fix run and the final browser script must provide final acceptance. No source file was changed while
that suite was executing.
