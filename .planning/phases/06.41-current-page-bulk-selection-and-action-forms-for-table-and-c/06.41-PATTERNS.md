## Shared Patterns

### Cooperative `checks()` on view classes
**Source:** `src/crud_views/lib/views/mixins.py` lines 136-142; `src/crud_views/lib/view/base.py` lines 1215-1221
**Apply to:** `BulkSelectionMixin`, `BulkFormViewPermissionRequired`
```python
    @classmethod
    def checks(cls) -> Iterable[Check]:
        yield from super().checks()
        yield CheckAttribute(context=cls, id="E202", attribute="cv_permission")
```
Always `yield from super().checks()` first. Existing checks already cover permission (`E202`, `E269`), modal
(`E251`, `base.py` lines 220-225), labels (`E110`, lines 204-208) and success/cancel keys (`E252`, `E253`,
`E256`, lines 226-246); add none for these.

### Translations
**Source:** `src/crud_views/lib/crispy/form.py` line 5; `src/crud_views/lib/views/mixins.py` line 13
**Apply to:** all new Python and template text
```python
from django.utils.translation import gettext_lazy as _   # class-level labels
from django.utils.translation import gettext as _        # request-time messages
```
Templates use `{% load i18n %}` with `{% translate %}` / `{% blocktranslate %}`. German entries go into
`src/crud_views/locale/de/LC_MESSAGES/django.po` and `src/crud_views_guardian/locale/de/LC_MESSAGES/django.po`,
compiled with polib (no `msgfmt` here). The Guardian check message uses non-lazy `gettext` inside the check
function (RESEARCH Pitfall 11); no existing check message is translated, so there is no in-repo analog for
that single line.

### Class keys instead of literal CSS classes
**Source:** `src/crud_views/templates/crud_views/snippets/card_order.html` lines 12-14;
`src/crud_views/templates/crud_views/tags/alert.html` lines 1-2
**Apply to:** `bulk_toolbar.html`, `columns/bulk_select.html`, `view_card.content.html`, the Option C leaf

Every literal `{% cv_button_class 'bulk' '<slot>' %}` needs a default key in `button_classes.py` and an entry
in the pinned inventories (`tests/test1/test_button_classes.py`, the "default table has 128 keys" sentence and
key table in `docs/reference/buttons.md`).

### Form posting back to its own URL
**Source:** `src/crud_views/templates/crud_views/view_custom_form.content.html` lines 5-6
**Apply to:** `view_bulk_form.content.html`
```django
<form class="cv-form" method="post" action="{{ request.get_full_path }}" … novalidate>
    {% csrf_token %}
```
`get_full_path` keeps the origin query string, so Cancel and the success redirect still resolve to the source.

### Scripts take text from markup
**Source:** `src/crud_views/static/crud_views/js/manage.js` lines 34-43; `view_manage.html` line 153
**Apply to:** `bulk.js`, `bulk_toolbar.html`
Server renders the translated control with `hidden`; the script binds listeners, then sets `hidden = false`.
No `innerHTML`, no storage, no requests.
