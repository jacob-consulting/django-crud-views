## 06.41-05

This is the security plan, and the three database checks are now isolated the way `cv_get_db_alias()` actually behaves.

- `cv_get_db_alias()` passes an instance hint only for a nested ORM request with a model in `self.object` (`src/crud_views/lib/view/base.py:369-379`).
