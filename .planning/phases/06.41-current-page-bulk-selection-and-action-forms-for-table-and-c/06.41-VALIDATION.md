## Sampling Rate

- **After every task commit:** Run `pytest tests/test1/test_bulk_*.py -n 4 -q` plus the inventory tests the
  task touched (`test_button_classes.py`, `test_label_mode*.py`, `test_button_data.py`, `test_pipeline_*.py`,
  `test_assets_bundles.py`, `test_js_no_jquery_guard.py`); `npx vitest run tests/js/bulk.test.js` for script tasks
- **After every plan wave:** Run `pytest tests -n auto`, `npx vitest run`, `ruff check` and
  `ruff format --check`; `mkdocs build --strict` when docs changed
- **Before `/gsd-verify-work`:** Full suite must be green on the cached Django 4.2, 5.2 and 6.0 environments
  with `PYTHONPATH=src`, plus the example project suite, then browser verification
- **Max feedback latency:** 30 seconds for the quick run
