## Shared Patterns

- **Validation/publication:** reject before scalar assignment, with no settings or strict-mode branch. Keep the exact ASCII grammar and full-string matching. Last successful startup call wins.
- **Rendering/escaping:** call-time getter and ordinary simple-tag return; retain Django escaping, existing translated labels, CSRF and aria/target linkage. All four templates already load the library.
- **Authorization/authentication:** no new guard or policy. Keep current inclusion contexts and existing permission decisions; prefix changes never grant action access.
- **Errors:** registry invalid input raises; missing adapter remains a no-op; malformed present adapter and provider errors continue to propagate. No catch-and-hide layer or new logging surface.
- **Lifecycle:** one `ownedTriggers` scan path serves init and dispose. Preserve ownership boundaries, marked root inclusion, ready/modal hooks and no show/focus.
- **Testing:** process state restoration with monkeypatch; real templates/real static scripts/actual docs fences. Broad Python commands use bounded `-n 4` in shared resources. Collect from `tests/test1` or `tests` with `-k` for object-detail selections, because directly selected nested conftest can import before Django configuration.
