## Shared Patterns

- **Tracked-source gate:** Every existing analog and regression source named here was confirmed by nonempty `git ls-files -- <path>` output from this worktree. No installed/runtime mirror is an analog.
- **Maintainability:** Make local consumption/class-string changes; preserve layout, auth, data attributes, escaping and validation. The five primary pattern families above are sufficient; no wider architecture search is needed.
- **Validation:** Contract parser verifies syntax/ownership; Python verifies real markup; Chromium verifies computed values. Keep these claims separate.
- **Errors and evidence:** Use assertions with explicit failure messages, nonzero browser exit, `finally` cleanup, explicit output destination and source fingerprints. Failed/environment-blocked browser execution cannot satisfy acceptance.
- **Scope:** No new dependencies, theme runtime state, Python settings, extension CSS work, downstream CoreUI/Tabler changes or data-prefix registration.
