### CR-01: Capture override can overwrite another file through an existing PNG symlink

**Classification:** BLOCKER
**Status:** fixed — independently verified on 2026-11-21T11:28:17Z
**Fix commit:** `19640864974cc2777ae28acdc91f79004011aab4`
**Category:** security
**File:** `/home/alex/projects/workspaces/cv-phase-06-44/django-crud-views/tests/browser/conditional-formsets.cjs:1169-1180`

**Issue:** The new preflight checks whether each destination pathname is ignored and untracked, but does not inspect the destination file itself. The ancestry check at lines 29–37 resolves only the capture root. If an existing `compact-lifecycle/invalid-390.png` beneath that ordinary root is an ignored, untracked symlink to a historical tracked PNG or a file outside the checkout, both Git checks succeed. `page.screenshot({path: capturePath})` then follows the symlink and overwrites its target. Checking the root and the index therefore does not enforce the override's file-preservation boundary. The checker at lines 225–234 likewise hashes the symlink target without rejecting it.

**Evidence:** Real read-only Git checks against the checkout's existing ignored `node_modules` symlink returned `check-ignore --no-index` status `0` and empty `ls-files` output: Git accepts an ignored symlink leaf, although it rejects traversal through an ancestor symlink. An in-memory invocation of the unchanged `compactCapture` using those Git outcomes reached the screenshot call with zero destination `lstat`/`realpath` inspections. The installed Playwright 1.64.1 implementation, `playwright-core/lib/coreBundle.js:63321-63324`, writes screenshot bytes with `fs.promises.writeFile(options.path, result.binary)`, which follows the leaf symlink. No real screenshot or target file was written during this investigation.

**Fix:** Before the first screenshot, validate every complete destination, including its existing leaf, rather than just the root. Reject symlink leaves (including dangling symlinks) and existing non-regular files; apply the same destination policy in the evidence checker. Retain the ignored/untracked checks and inspect all planned outputs before any write. Add a regression where an ignored, untracked later PNG is a symlink to a protected file: the writer must reject before its first screenshot and leave the target untouched. This can remain a small test-local helper without changing the product API or historical default capture behavior.
