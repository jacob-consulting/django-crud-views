## Shared Patterns

### Destination access/state gate

**Source:** `src/crud_views/lib/view/base.py`, lines 76–88. **Apply to:** only the effective-key computation on the source instance.

```python
def _cancel_target_available(target, user, obj, rendering_view):
    """Evaluate the concrete destination's access and state hooks, including overrides."""
    target_obj = obj if target.cv_object else None
    if not target.cv_has_access(user, target_obj):
        return False
    if target.cv_object:
        return target._cv_action_enabled_for_rendering(user, target_obj, rendering_view)
    action_obj = None
    if target.cv_viewset.has_parent:
        action_obj = rendering_view._cv_cancel_parent_object()
        if action_obj is None:
            return False
    return target._cv_action_enabled_for_rendering(user, action_obj, rendering_view)
```

Call `_cancel_target_available(destination, self.request.user, None, self)` directly. Bulk destinations already declare `cv_object = False` (bulk module line 207). Avoid the Cancel-specific overridable wrapper at base lines 990–992 and avoid a separate permission/state implementation.
