## Warnings

### WR-01: The bulk leaf contract incorrectly promises an empty unavailable icon

**Classification:** WARNING  
**File:** `/home/alex/projects/workspaces/cv-phase-06-47/django-crud-views/docs/reference/buttons.md:661`  
**Issue:** The new public field table calls `cv_icon` a resolved icon name and promises an empty value when unavailable. The actual payload retains the destination's nonblank icon string. For a destination with `cv_icon_action = "delete"`, `CRUD_VIEWS_ICONS = {"delete": None}` and bulk icon mode, the source renderer supplies `cv_icon == "delete"`, `cv_label_mode == "label"`, `cv_icon_inline is True` and `cv_icon_class == ""`. Mapping the icon to `""` has the same result. Even the available default case supplies the semantic name `"delete"`, not its resolved library name.

The source changes only the mode when availability fails (`src/crud_views/lib/bulk/__init__.py:118`); the form normalizer converts blank/non-string input to `None` but otherwise preserves the string (`src/crud_views/lib/view/button_data.py:328-332,388`). Thus a theme author following this public contract cannot use the icon field's truthiness as an availability signal. A copied customization could select icon-specific layout or wrappers for a disabled icon. The stock leaf itself remains correct because it branches on the effective mode. The new copied-contract test exercises only available inline and host icons, so its successful output comparisons do not verify this documented unavailable-value promise.

**Evidence:** A direct property invocation, mocking only the source context/URL and destination label to avoid database work, captured:

```text
CRUD_VIEWS_ICONS={}:
  cv_icon='delete', cv_label_mode='icon'
CRUD_VIEWS_ICONS={'delete': None}:
  cv_icon='delete', cv_label_mode='label'
CRUD_VIEWS_ICONS={'delete': ''}:
  cv_icon='delete', cv_label_mode='label'
```

**Fix:** Correct the field description to state that `cv_icon` is the destination's normalized icon string (semantic name, library-prefixed name or raw class string), or `None` for blank/non-string input; it can remain nonempty when unavailable. Tell copied leaves to honor `cv_label_mode` and render through `cv_icon` rather than infer availability from truthiness. Add a disabled semantic-icon case to the existing copied-leaf contract test, asserting both the retained name and label fallback. Preserve the existing normalizer and stock rendering behavior.
