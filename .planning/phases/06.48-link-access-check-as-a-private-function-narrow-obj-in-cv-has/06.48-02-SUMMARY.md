## Own-Denied Navbar Child Items Now Run the Parent Gate (C2)

At a navbar child item the parent gate now precedes own access. An actor whose own access would deny therefore reaches the parent gate and pays for it. A malformed parent permission mapping, missing operation declaration or wrong auth database raises `ImproperlyConfigured` for both possible own-access answers; neither the own-access hook nor state hook runs after that error.

`test_reached_policy_errors_propagate` pins all six combinations. Well-formed-policy rendered results remain unchanged. The existing cost suite grants its actors, so every pinned query total stays identical; its old own-denied behavior was an asserted, unmeasured row in `06.48-COST-BASELINE.md`. Plans 04 and 09 must carry this C2 change into the adapter and after-records.
