## Adapter record (acceptance criterion of issue #407)

| Private adapter | State after this plan |
|-----------------|-----------------------|
| `_cv_child_link_has_access` | Removed. Replaced by `_cv_link_permission`, whose `obj` is only the target's own object and whose parent is a separate argument. The replacement asks the parent gate before own access, where the adapter asked own access first. | `_cv_action_enabled_for_rendering` | Remains for stage 3. Still called by context buttons, actions by view key, the parent button, the sibling button, the non-child card action, the navbar owner item, the cancel target and the bulk toolbar. |
