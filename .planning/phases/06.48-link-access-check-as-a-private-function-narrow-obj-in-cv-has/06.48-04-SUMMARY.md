## Own-Denied Child Links Now Run the Parent Gate (C2)

The parent gate precedes own access at the child context button and card child action from this plan on, and at the object navbar child item since plan 02. An actor whose own access would deny pays for that gate. A malformed permission mapping, missing operation declaration or wrong auth database therefore raises `ImproperlyConfigured` for that actor too; own access and state are not reached after the error.

The new `own_denied` receipts for both context and card measure **one helper call, two permission queries**, after the existing fixture setup. Anonymous and inactive cases still make no gate call and no query. This is the named changed cost; the granted-actor navbar and ancestor measurements remain unchanged.
