## Sampling Rate

- **After every task commit:** Run the quick run command, plus the test file the task touches.
- **After every plan wave:** Run `pytest tests -n auto`.
- **Before `/gsd-verify-work`:** Full suite green, `mkdocs build --strict`, `task format` and `task check` clean,
  the example suite green (`cd examples/bootstrap5 && uv run pytest`), and the static `git diff` checks below.
- **Max feedback latency:** about 10 seconds per task; about 500 seconds per wave.
- A serial run is justified only for a single failing test under investigation.
