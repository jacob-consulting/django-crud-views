## Shared Patterns

- **Actor, validation and error boundaries:** keep each caller's current actor/default-database/vocabulary checks; helper acquisition has no authorization policy. Request denial still raises `PermissionDenied`, callable denial remains `False`, configuration errors propagate.
- **Lazy and optional imports:** local Guardian import matches the accessor and current own-access branches. Use ordinary attributes on the user; avoid wrapper `__dict__` mutation, globals, settings and class-level checker state.
- **Trace separation:** existing recorders own final events; helper records no new event. State remains destination-specific. Do not reorder ordinary row/context state handling.
- **D-37 repeated checks:** direct repeated own access, ancestor followed by controls/Cancel, workflow refusal reload and delete-page controls use loaded grants. Bulk review/confirmation are separate requests; stock bulk application hooks and delete related-label queryset shortcuts stay independent, as mapped in RESEARCH.md. No extra refresh gate is justified by these paths.
- **Evidence before new pins:** measurement fixture first, actual before receipt, helper replacement, actual after receipt, then numerical documentation. Preserve semantic assertions throughout; no `prefetch_perms` or timing claim.
