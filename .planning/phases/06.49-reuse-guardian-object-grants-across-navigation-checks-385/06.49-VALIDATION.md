## Sampling Rate

- After each task: run the affected test or small parameter group named in its `<verify>` block.

- Before phase verification: run the full suite with multiple workers, relevant example checks, strict docs and Ruff.
- Feedback target: keep focused checks under 60 seconds where practical; report observed time rather than asserting
  an unmeasured bound. Broad regression runs may take longer.
- Every runnable `<automated>` command must have an immediately following `<fails_when>` describing observable
  failure, including collection failure or a nonzero exit. No watch mode.
