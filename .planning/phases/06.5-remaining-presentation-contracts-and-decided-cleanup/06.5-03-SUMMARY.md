# Phase 06.5 Plan 03: Object-detail render projection Summary

**Tabs and accordions now share immutable per-render target identities; the first tab and panel agree, and copied group-only layouts retain their enclosing projection.**

## Accomplishments

- Generated component IDs use `g` plus UUID hex, length-delimited component tokens, positional group suffixes and paired control/panel suffixes. Display titles never determine targets. Supplied component tokens receive strict full-match validation.
- Tabs expose `data-cv-od-tabs`, explicit selected state, roving trigger tabindex and the stock panel reading stop (`tabindex=0`). Empty inputs have no selected pair.
- Accordion buttons and panels share reciprocal targets and reference only their actual root. Initially collapsed behavior is retained. Standalone accordion groups omit `data-bs-parent`; standalone tab panels use an escaped title label instead of an absent control reference.
- Both interactive layouts use the shared heading-icon projection on the title-bearing button, including host-class escaping and exactly one element icon.
- The shipped fallback iterates `component.groups`, passing each original group and its existing presentation to copied layouts. All five group-only packs prove supplied component stability, distinct positional entries, first selection, escaping and generated-component isolation.
