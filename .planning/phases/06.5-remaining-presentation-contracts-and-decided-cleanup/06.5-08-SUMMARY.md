# Phase 06.5 Plan 08: Real-browser presentation acceptance Summary

**Authenticated Chromium runs prove stock tab keyboard/focus behavior, isolated stable selectors, mixed heading icons and escaped native badge projection using verified versioned CDN assets.**

## Accomplishments

- Added a separate temporary-SQLite/media fixture bound to 127.0.0.1. Real `ObjectDetailViewPermissionRequired` dispatch and real modal HTTP requests use the package's authorization and modal paths. Explicit component IDs use `cv_is_modal_request(self.request)` to choose `author-page` or `author-modal`.
- Both entry points validate `CV_PRESENTATION_PORT` before Django setup, probing, binding, browser discovery or navigation. Unset means 8145; explicit empty/malformed/out-of-range values and reserved 8143/8144 fail with an actionable diagnostic. Invalid runtime overrides never silently fall back.
- Exercised one/two-group, plain/link-content, page/modal cases: first selection, first-key activation before any tab click, mouse activation, ArrowUp/Down wrapping, Home/End, reciprocal control/panel IDs, selected state, visible panels and exact `document.activeElement` destinations. Tab enters the selected projected panel, then its link or the after-tabs sentinel. Hidden panels are not visited.
- Exercised real modal replacement, completed close, reopen and return to the accepted opener. Bootstrap fade completion is awaited before evaluating final panel state. Replacement listeners are registered before the HTTP request to avoid a localhost response race.
- Proved independent sibling/page/modal tab selection and two independently targeted accordions with repeated, empty, punctuation and Japanese titles. Every accordion control points to its own panel and parent; generated namespaces differ across repeated renders.
- Activated `gettext_lazy("January")` and `gettext_lazy("February")` under allowlisted en/de translation overrides spanning dispatch and `TemplateResponse.render()`. English/German text differs, while exact explicit page/modal selectors survive reload, translation and reordered groups.
- Used actual Font Awesome 6.7.2 glyphs for a host-placement test library and the existing element renderer. Verified page/modal/group placement, single glyphs, visible titles/accessible heading and tab names, empty/disabled icons, changed semantic heading levels, and replaced/removed size classes.
- Added a native noninteractive layout and request-isolated badge override. Actual resolved group/property/value/settings context survives; hostile title/value/color text is escaped; arbitrary semantic colors and pill states map to native classes. No Bootstrap assets or markup are required by this native fixture, and its loader does not affect the next stock request.
