## Shared Patterns

- **Imports:** absolute package imports for cross-package helpers; relative imports within tightly related modules. Deferred imports where template libraries load before app registration (formset inclusion tag).
- **Escaping:** `conditional_escape` for dynamic heading attributes; normal Django autoescaping for context values; `mark_safe` only around markup assembled from already escaped/template-rendered pieces. Preserve resolved property/value context.
- **Errors:** Pydantic ValueError for invalid supplied model input; Django TemplateSyntaxError for malformed tag syntax. New registry collision error type/message is a planning choice; report supplied identities rather than silently suffixing them.
- **Authorization:** no new auth layer is needed here. Existing ObjectDetailMixin uses the view's resolved object; render projections must not re-query or bypass accepted data filtering.
- **State:** copy caller context and explicitly carry private render scope across template boundaries. Never persist IDs on resolved groups, compiled nodes, process globals or session state. JavaScript global guards prevent duplicate listener registration, not shared component selection.
- **Regression boundary:** preserve accepted form/cancel, native conditional/formset, modal focus, auth and delete contracts. Use focused suites during edits and full supported-series/browser/JS gates from RESEARCH.md before claiming completion.
