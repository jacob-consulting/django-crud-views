## Identity inputs and theme projection

| Exact input / field | Producer and consumer |
|---|---|
| `PropertyGroupConfig.id`, `ResolvedGroup.id` | `src/crud_views_object_detail/lib/config.py`, `resolvers.py`; optional stable group key |
| `cv_object_detail_id`, `cv_get_object_detail_id()`, projected `object_detail_id` | `lib/mixins.py`; stock `view_detail.content.html` forwards the view's token |
| `render_object_detail(..., component_id=None)` | `templatetags/crud_views_object_detail.py`; raw template entry point |
| `component.id`, `component.tablist_id`, `component.content_id`, `component.groups` | `lib/presentation.py` produces the immutable template projection; object layout templates consume it |
| `presentation.group`, `presentation.control_id`, `presentation.panel_id`, `presentation.selected` | Each `component.groups` entry; same entry passed to group template |
| `render_group(group, layout=None, presentation=None, component=None)` | Existing group render entry point with enclosing presentation/component arguments |
| `groups`, `group`, `layout`, `prop`; value template `prop`, `value`, `od_settings` | Retained resolved context through object/group/property/value templates; native recipe executes these fields |

Supplied tokens match `[A-Za-z][A-Za-z0-9_-]*` exactly; None means omitted, empty/non-string/invalid
tokens fail. Component base is `cvod-c{len(C)}-{C}`. Its suffixes are `-root`, `-tabs`, `-content`.
Explicit group key uses `-s{len(G)}-{G}-control` / `-s{len(G)}-{G}-panel`; omitted group key uses
zero-based `-i{index}-control` / `-i{index}-panel`. Omitted component identity is generated afresh.
The first entry has `selected=True`; tabs share it across control/panel, accordions stay collapsed.
Stable group keys survive translated labels/reordering; positional keys do not survive reordered meaning.

Duplicate supplied identity raises `ImproperlyConfigured` within the shared outer Template.render scope,
including sibling includes/inheritance and explicitly transported library backend rendering. Fresh backend
render_to_string with a new dict/Context without the private scope transport starts an independent boundary,
even when its output is assembled into the same page. Independently fetched responses have the same
application-owned uniqueness obligation. No public registry transport is introduced.

Evidence: `tests/test1/od/test_object_detail_identity.py`, `test_object_detail_view.py`, `test_config.py`,
`test_layout_packs.py`, `test_layout_a11y.py`; `tests/test1/test_presentation_migration_docs.py` executes
actual copied/native fences, en/de month translations, page/modal hook, collisions and fresh backend boundary.
Migration: `docs/migrating-1.0.md#interactive-object-detail-templates-and-targets`.
Recipes/formula/boundary: `docs/reference/object_detail_layout_packs.md`;
inputs/hook: `docs/reference/object_detail_configuration.md`.
