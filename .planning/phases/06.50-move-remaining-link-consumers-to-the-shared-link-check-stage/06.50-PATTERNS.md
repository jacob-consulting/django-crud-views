**Core permission/state pattern:** `link_access.py:80–90`:

```python
def _link_access(target, user, obj=None, known_ancestors=(), *, rendering_view=None) -> str:
    """Evaluate state only after permission passes, using the request's action-object rule."""
    if not _link_permission(target, user, obj, known_ancestors, rendering_view=rendering_view):
        return _LINK_PERMISSION
    action_obj = obj if target.cv_object else known_ancestors[0] if target.cv_viewset.has_parent else None
    return _LINK_ALLOWED if target.cv_action_enabled(user, action_obj) else _LINK_STATE


def _link_ctx(outcome: str) -> dict:
    """Stamp the existing visibility fields; permission denial leaves state unevaluated."""
    return {"cv_access": outcome != _LINK_PERMISSION, "cv_action_enabled": outcome != _LINK_STATE}
```

**Guard input pattern:** `ancestors.py:576–585`:

```python
def _resolved_ancestor(view: CrudView, name: str) -> Model | None:
    """The ancestor of ViewSet ``name`` resolved by a successful guard on this request, or None (no guard state,
    or ``name`` is not in the view's ancestry). Lets request helpers reuse the resolved identity."""
    state = getattr(view, "_cv_ancestor_state", None)
    if state is None:
        return None
    for (_, ancestor), obj in zip(_walk_ancestors(view.cv_viewset), state.objects, strict=True):
        if ancestor.name == name:
            return obj
    return None
```

Use `_walk_ancestors(target.cv_viewset)` (`ancestors.py:89–120`) as the destination's nearest-first declaration list, then resolve each declared ViewSet name. Preserve `None` entries. The helper must additionally accept the explicit URL parent for child/Cancel paths; this is new bounded composition, not a pattern already implemented by `_resolved_ancestor`. Do not copy the rendering page's tuple by index. `_walk_ancestors` already validates missing declarations/cycles with `_AncestryError`; no new catch should hide those errors.

Remove `_page_action_object` after its consumers migrate. Do not replace it with another state-only adapter. `_link_permission` already denies missing immediate parents and validates higher gates before own permission (`link_access.py:68–77`).

def _cv_cancel_parent_object(self):
    """Only the built-in missing-row lookup makes a destination unavailable.

    Application overrides own their exceptions, including Http404. Missing URL
    kwargs and database failures are programming/operational errors, not denial.

    lookup = self.cv_get_parent_object

## Shared Patterns

- **Permission before state:** copy `link_access.py:80–85` at every full consumer. Permission-only filter uses lines 68–77. `_link_ctx` preserves the published visibility shape.
- **Target alignment and identity:** declared target ancestry plus `_resolved_ancestor`; explicit child URL object fills the immediate parent. Preserve holes. Pass the rendering view only when `target.cv_viewset is rendering_view.cv_viewset`, otherwise `None`.
- **Retained seam:** an explicit seam tuple remains authoritative at its existing consumers. A core `None` requests normal aligned ancestors. Navbar child items bypass the seam by D-55.
- **Errors remain observable:** `_walk_ancestors` validates declarations; checker configuration errors propagate. Only built-in Cancel missing-row lookup is converted to unavailable. Do not broaden exception handling.
- **Guardian preservation:** no source changes are assigned to `GuardianQuerysetMixin._cv_link_permission`/`cv_get_context`, Guardian create seam/permission overrides or the three Cancel overrides. Retain the context/rendering state adapters. Test the approved higher-gate narrowing separately from these surviving exceptions.
- **Validation:** no new framework or schema. Use existing pytest/pytest-django fixtures and public hook spies. Broad execution uses the research command's `PYTHONPATH=src:. CV_ACCESS_RECORD_REQUESTS=0` and `-n 6`.
