**Verified observation; no defect:** All four context-button migrations retain `_apply_label`, `_apply_variant` and template selection. The label helper still applies an explicit label to both full and short labels (`src/crud_views/lib/view/buttons.py:70`, `:124`, `:194`, `:250`, `:317`). Navbar label selection and plain-text handling remain intact (`src/crud_views/lib/navbar.py:105`). Card own and child branches preserve their label, icon, variant and label-mode fields (`src/crud_views/lib/views/card.py:63`, `:102`). The card regression explicitly asserts these fields after each permission/state outcome (`tests/test1/test_link_consumers.py:1239`).

The navbar template retains its translated object-specific landmark name (`src/crud_views/templates/crud_views/tags/navbar_items.html:1`). Supporting tests cover German translation, escaping and complete long labels (`tests/test1/test_navbar_templates.py:286`, `:307`, `:406`). The bulk return test asserts the existing actionable warning, blocked reason and Cancel label (`tests/test1/test_bulk_return.py:358`). No new end-user empty/error/CTA string was introduced by the permission migration. Generic-label heuristics do not justify renaming the existing Cancel control in this scope.

### Pillar 6: Experience Design — 4/4, source/HTML behavior

**Verified observation; no phase defect:** The shared check denies an unknown immediate parent, checks supplied higher ancestors and own permission, then evaluates state. Permission denial leaves state unevaluated (`src/crud_views/lib/link_access.py:70`, `:82`). All four button consumers, view-key context/table actions, own/child cards, navbar destinations, permission filter, core Cancel and bulk admission use the intended shared path. The filter deliberately calls `_link_permission`, never state (`src/crud_views/templatetags/crud_views.py:651`).

The resulting fields retain the existing distinction between permission and state denial. `cv_resolve_action` hides the action or clears its URL and sets the disabled reason (`src/crud_views/lib/view/visibility.py:14`). The unchanged button normalizer chooses a native disabled button and removes navigation, modal and submission behavior (`src/crud_views/lib/view/button_data.py:133`; `tests/test1/test_button_data.py:77`). Hidden/disabled row and context actions produce no hidden POST form (`src/crud_views/templatetags/crud_views.py:143`, `:270`). The new checks therefore connect to usable rendering behavior rather than merely setting an unused flag.

Concrete coverage examined:

- **Permission-specific links:** A real allowed page keeps its permitted list link, hides an update link whose request returns 403, and restores it for a fresh granted actor (`tests/test1/test_link_consumers.py:593`). Context/table render tests check actual output for update/delete/create denial and granted controls (`:1076`). Own/child card cases assert exact row/ancestor identities and presentation fields (`:1205`).
- **Navbar:** Unavailable items are omitted, all-hidden output is exactly empty, partial links preserve order/current-section semantics, and separate requests do not share results (`tests/test1/test_navbar_templates.py:233`, `:249`, `:334`). The branch changes do not introduce asynchronous loading, spinner or error-boundary requirements.
- **Bulk source:** Admission directly checks the destination with guard state (`src/crud_views/lib/bulk/__init__.py:105`). Table/card tests assert no action and no item selectors after immediate or farther denial while preserving independent POST 403 and unchanged data (`tests/test1/test_bulk_scope.py:500`). Thus users are not offered selection controls with no eligible action. Permitted controls and exact state-parent identity remain covered (`tests/test1/test_link_bulk.py:58`, `:81`).
- **Cancel and returns:** Core Cancel uses the existing parent hook and permission-aware origin/fallback selection (`src/crud_views/lib/view/base.py:77`, `:1012`, `:1041`). D-52 tests separately assert GET, warning POST and all-blocked Cancel destinations for origin/fallback/success, preserve query rules, and prove no write occurs (`tests/test1/test_bulk_return.py:326`). Authorization still precedes return navigation (`:389`).

**Accepted contract boundary, not a finding:** D-55 intentionally permits a same-page Guardian context create control while hiding its navbar child-create item when a stricter higher gate denies. The test asserts both outcomes and the destination response (`tests/test1/test_navbar_permissions.py:268`). The retained create seam/rewrite, queryset-only nearest skip and separate Guardian ParentPermission Cancel behavior belong to the approved stage-3a boundary. They must not be mislabeled as new defects or silently certified as complete link/request equivalence.

Actual keyboard traversal, tooltip behavior, focus indication, menu operation, browser navigation and downstream overrides were not exercised. The experience score covers the bounded source/HTML behavior above only.
