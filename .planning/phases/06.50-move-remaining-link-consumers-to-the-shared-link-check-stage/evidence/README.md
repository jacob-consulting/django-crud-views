# Phase 06.50 evidence

These files retain the exact Git blobs referenced by the phase reports, including original failed runs and later passing results. The filename is the Git blob ID; index.json records byte counts, SHA-256 hashes and reachability before retention. Committing these files makes the original blob IDs reachable and transferable in a normal clone. No original receipt or report measurement was rewritten.

The files contain test output, XML and audit scripts as inert evidence. They are not installed or executed by the package, and the entire planning directory remains excluded from distributions.
