## Protocol and measured interpretation

Source request guards resolve their real ancestors outside capture. Rendering uses the exact known parent identities. Cold users are new ORM User instances; warm users execute the same consumer once without retaining decisions. Permission vocabulary is reset **after** actor warm-up, making warm-user/cold-vocabulary an independent control. Fresh cases first render with opposite grants, change real model/object change grants, then fetch a distinct User and prove the result changes. Retained old users are not invalidated.

SQL, SQL categories, domain lookups, ancestor/own/create/state calls, exact actor/parent/row identities, actual results and prior fresh-user results are recorded separately in XML. No ordinary consumer loads domain rows. Guarded Cancel reuses its parent with zero domain lookup; unguarded and built-in missing-parent Cancel issue one Book lookup. Missing parents perform no permission/state work. Denied gates never call state or the create hook. Permission filters never call state.
