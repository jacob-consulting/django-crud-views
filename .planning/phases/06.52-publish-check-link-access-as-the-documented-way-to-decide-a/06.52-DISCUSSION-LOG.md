## Edge cases

### 1. What should happen if the target class has no ViewSet?

| Option | Description | Selected |
|--------|-------------|----------|
| 1 | Raise ImproperlyConfigured explicitly (recommended) | ✓ |
| 2 | Leave unsupported, with no explicit check or exception guarantee |  |

**User's choice:** 1: Raise ImproperlyConfigured with an explanation that check_link_access requires a target with a ViewSet, before evaluating permissions or state.

### 2. Should an unsaved Django model instance be accepted as the own object?

| Option | Description | Selected |
|--------|-------------|----------|
| 1 | Reject unsaved own model instances with ImproperlyConfigured (recommended) |  |
| 2 | Accept by model type and delegate to existing hooks | ✓ |

**User's choice:** 2: Accept it. Validate its model type, then let permission and state hooks evaluate it; hook errors propagate normally. Do not reject it merely because it is unsaved. Resource instances have no Django persistence state.

**Notes:** The user chose acceptance over the assistant's suggested saved-instance-only
restriction. The context records the user's choice, with normal hook results/errors retained.
