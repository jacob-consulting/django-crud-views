**Primary analog:** existing same-module private full check, lines 81–86:

```python
def _link_access(target, user, obj=None, known_ancestors=(), *, rendering_view=None) -> str:
    """Evaluate state only after permission passes, using the request's action-object rule."""
    if not _link_permission(target, user, obj, known_ancestors, rendering_view=rendering_view):
        return _LINK_PERMISSION
    action_obj = obj if target.cv_object else known_ancestors[0] if target.cv_viewset.has_parent else None
    return _LINK_ALLOWED if target.cv_action_enabled(user, action_obj) else _LINK_STATE
```

## Shared Patterns

- Validation is metadata-only and precedes all gates, for ordinary, anonymous and superuser callers alike. Spy that invalid inputs never reach delegation/hooks.
- Existing private checker owns parent → own permission → state order and action-object identity. No request authorization or Guardian policy rewrite belongs in this phase.
- Compare public results by enum member identity and assert both denials false and unequal to raw strings. Preserve private string assertions/signature tests.
- Never normalize supplied ancestry by dropping `None`, fetching missing levels or guessing parent relations. Three-level interior-hole tests matter.
- Preserve private bodies, current consumers, published context formats, request responses, grant-checker lifetime and all golden/matrix/cost baselines. Read `tests/test1/test_link_access_matrix.py` and `tests/test1/test_link_consumer_costs.py` only when later verification needs their gates; do not edit pins or historical receipts to accommodate the wrapper.
