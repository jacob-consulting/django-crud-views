## Decisions and Custom Opt-in

```python
class ActionClassesMixin:
    def get_form_actions(self):
        group = super().get_form_actions()
        group.css_class = "my-actions"
        return group
```

Put it before an ordinary form or filter-helper class. The returned library group combines authored and current registered classes. A wholly replaced provider remains unchanged; a custom pack must consume formactions.css_class itself. The real Tabler pack is still plan 07 acceptance work.

## Post-wave integration correction — 2026-11-02

Wave 2's full Django 5.2 run found one integration failure: `test_button_chain_renders_only_table_classes`,
with 8632 passed and 1 skipped (210.97s). Original output remains `/tmp/phase-06.6-wave2-pytest.log`.
The focused real-request reproduction also failed: `/publisher/` and both ordered-card URLs reported
`('div', 'mb-3')`; report `/tmp/phase03-wave2-red.xml`, 1 failed in 1.06s.

**Root cause:** the rendering guard automatically includes every new class utility in its sentinel map.
The new additive group utilities therefore brought the pack-owned action wrapper into a guard that assumed
all sentinel-styled elements had wholly replaceable classes. The installed Bootstrap template already owns
`mb-3`, and UI-SPEC explicitly requires group utilities to supplement pack wrappers. Removing that class
from product output would violate D-17 and the empty-value byte-preservation tests.

**Correction:** permit only `mb-3` on the sentinel-bearing `div` for `form:actions` or
`form:filter-actions`. Keep both utilities in the sentinel scan. Do not exempt their descendant labels,
buttons, unrelated elements, other class tokens, or the pack globally. No product code/template changed.

Added real ordinary/filter renderer guard regressions and negative mutation controls. Before the guard
fix, both wrapper acceptance cases failed and the three unrelated-element controls passed (0.23s);
`.git/gsd-plan03-wave2-red.json` received `RED_EVIDENCE_OK`. RED commit: `0e51c2c`.
After correction, the renderer/guard/filter/golden integration selection passed **147 tests in 6.89s**
with four workers. Injected `mb-3` on buttons/labels and `mt-4` on group wrappers are still detected;
wrong tag/sentinel combinations remain rejected. Ruff and whitespace checks passed.
