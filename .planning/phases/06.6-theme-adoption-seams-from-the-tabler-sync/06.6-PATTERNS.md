## Pattern Assignments

### Registry and label floor

**Apply to:** `src/crud_views/lib/view/label_mode.py`, class registry and associated tests/docs.
**Primary analog:** `src/crud_views/lib/button_classes.py` lines 135–151.

```python
def register_button_classes(classes: dict[str, str | None]) -> None:
    """Theme API: merge ``classes`` into the theme layer (settings still win)."""
    _THEME_BUTTON_CLASSES.update(classes)
    reset_button_classes_cache()


def _settings_layer() -> dict[str, str | None]:
    return getattr(settings, "CRUD_VIEWS_BUTTON_CLASSES", None) or {}


def get_button_classes() -> dict[str, str | None]:
    global _button_classes_cache
    classes = _button_classes_cache
    if classes is None:
        classes = {**DEFAULT_BUTTON_CLASSES, **_THEME_BUTTON_CLASSES, **_settings_layer()}
        _button_classes_cache = classes
    return classes
```

Copy the per-key ordering, not the unvalidated registration body: `register_label_mode_defaults()` must validate the **entire** mapping before committing, copy caller values, merge later registrations and leave prior state intact on any invalid entry. Prefer the existing lazy resolver rather than introducing a second cache.

### Strict diagnostics and fallback

`src/crud_views/lib/view/label_mode.py` lines 71–83:

```python
from ..exceptions import is_strict

if is_strict():
    raise ValueError(f"{source}, got {value!r}")
resolved = fallback()
pair = (location, repr(value))
with _warned_lock:
    first = pair not in _warned
    if first:
        _warned.add(pair)
if first:
    logger.warning("%s, got %r; the %s button uses %r", source, value, location, resolved)
```
