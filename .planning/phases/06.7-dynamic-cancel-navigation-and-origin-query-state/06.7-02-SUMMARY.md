# Phase 06.7 Plan 02: Permission-aware cancel destinations Summary

**Cancel applies the destination's core or Guardian policy, diagnoses invalid fallback configuration with E256, and evaluates target state once per form-button render.**

## Accomplishments

- E256 applies only to FormMixin owners, including the polymorphic selector. An unavailable configured fallback is a startup error when no registered structurally usable allowed origin exists; static forms always report an invalid fallback. Detail/list-only owners remain unaffected. E255 retains its independent context-button diagnostic.
- Runtime configuration errors identify the class and effective fallback key and request a registered usable destination. None resolves to the current key; list retains card fallback. A valid origin does not resolve an invalid fallback. Invalid origin routes fall back; an unusable configured route raises ImproperlyConfigured. Registered-but-denied destinations return None in hide and disable modes.
- Access precedes the existing rendering adapter. Saved model/Resource objects reach object targets; nested no-object targets receive the current URL parent. Repeated origin/fallback identity shares one availability evaluation within a resolution. Missing kwargs, database errors and custom Http404/KeyError hooks propagate; built-in missing-parent lookup returns unavailability.
- Guardian validates mixin composition, rejects anonymous/inactive actors, and applies the destination's parent policy before child/object/state checks. Object grants and per-view global opt-in remain authoritative. Queryset targets admit an empty visible list. Parent-only targets avoid inappropriate child/model permission checks. Nested create targets invoke cv_create_has_access with the resolved parent and the rendering owner.
- Same-user requests follow emitted Cancel links. The create-only parent grant case hides a forbidden list destination yet allows the form POST. Custom parent-only and nested-create routes work with parent grants and no child-model grants, reject other parents, and preserve parent-None existence/state checks.
