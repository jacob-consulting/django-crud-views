## Pattern Assignments

### Resolver, defaults and link capture

**Analog:** `src/crud_views/lib/view/base.py`, 752–772. Retain saved-object usability, including UUID instances with populated but unsaved PKs:

```python
state = getattr(obj, "_state", None)
unsaved = state is not None and state.adding
if cls.cv_object and (obj is None or unsaved):
    return self.cv_cancel_key
```

**Link emitter**, same file, 808–815:

```python
url = self.cv_get_url(key=key, obj=obj)  # reverse() only, never has a query string
origin = self.cv_get_link_origin_key(cls)
if origin:
    url += "?" + urlencode({crud_views_settings.origin_param: origin})
return url
```

Extend this single emitter for cancel capture; row/context/card integrations already call it. Continue server reversal with current parent kwargs, not payload-provided destinations. Keep success origin independent. Existing `cv_cancel_keys=None` is static: automatic defaults require a distinguishable representation, resolved after sibling registration. Explicit lists retain custom keys. Existing checks and metadata must understand the representation.

**Shared context**, same file, 817–824, currently unconditionally returns:

```python
url = self.cv_get_url(key=self.cv_get_cancel_key(obj), obj=obj)
return {"cv_url": url, "cv_action_label": _("Cancel")}
```

Replace this resolution seam with the shared URL/omission outcome. Invalid request data falls back; missing developer fallback raises a clear configuration error; registered inaccessible origin/fallback omits Cancel. Do not copy its current disregard of `user`.

### Access/state policy and Guardian

Reuse hooks, but enforce the phase's access-before-state ordering and correct target action object. Cancel always hides inaccessible destinations, irrespective of generic hide/disable policy. A list target must not receive the child object as its state object.

## Shared Patterns

- Keep `cv_` configuration attributes, double quotes, 120-column Python, current imports and lazy Guardian imports.
- Reverse same-ViewSet destinations with current object/parent. Access hooks are rendering policy; actual destination authorization remains authoritative.
- Capture query on link emission, independent of session changes; preserve transport through invalid submissions without changing success redirects.
- Shared URL resolution feeds every cancel rendering surface. Preserve autoescaping, CSRF, one outer form and protected-delete omission.
- Use source-bound pytest (`PYTHONPATH=src`) with bounded workers for broad runs; existing cached installs can be stale. RESEARCH.md contains the verification matrix. This mapping ran no tests.
