### Pillar 6: Experience Design (3/4)

**PASS:** `base.py:845–900` resolves an allowed accessible origin, accessible fallback, or omission; it uses the current saved object and returns a URL without dispatching a mutation. `form.py:92–110` prevents custom kwargs from undoing bound-view permission omission while preserving standalone custom helper compatibility. `src/crud_views/templatetags/crud_views.py:281–289` delegates the template route to the same resolver and does not swallow configuration errors.

**PASS:** The native anchor branch in `tags/button/form.html:1–2` has an escaped href and no generated button submit attributes or delegated Cancel data attribute. `button_data.py:354–365` restricts anchors to a usable URL and no emitted disabled attribute; a caller-disabled standalone leaf retains its native button behavior.
