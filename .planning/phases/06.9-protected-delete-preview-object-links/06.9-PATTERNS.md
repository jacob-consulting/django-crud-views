## Shared Patterns

* **Authorization:** destination class access/state hooks plus Guardian parent composition; queryset membership remains separate. Actual destination requests stay authoritative.
* **Errors:** distinguish expected missing route/row and denied access from broken custom hooks/configuration/database operations. No blanket exception suppression.
* **Presentation:** ordered `obj`/optional `url` dictionaries only at template boundary; keep provider/filter models unchanged and cascade behavior intact.
* **Escaping/theme:** shared `cv_alert` frame, specialized caller-context body, explicit autoescaping; no generic alert-item API change.
* **Verification:** source imports, exact executable documentation fences, owned browser resources and bounded multicore pytest for broad runs.
