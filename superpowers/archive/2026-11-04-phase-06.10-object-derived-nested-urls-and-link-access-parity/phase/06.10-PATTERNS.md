## Shared Patterns

- Absolute package imports plus local relative imports follow surrounding modules; optional Guardian imports remain lazy in core delete certification.
- Request authorization and queryset scope remain authoritative. Resolver results are coordinates, not membership/access certification.
- Access and state remain separate context fields; missing declarations deny link access before permissive permission fast paths.
- Only recognized resolution unavailability is optional. Explicit conflict/wrong model and unexpected custom-code exceptions propagate, including under `strict=False`.
- Use fresh instances and explicit metadata/checker warmup for query assertions; no cross-request permission cache.
- Follow CLAUDE.md: double quotes, 120-column Ruff formatting, multicore broad pytest; Breaking changelog entry accompanies migration guidance.
