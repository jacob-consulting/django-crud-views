# Ruff 0.16 Explicit Rule Set — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adopt ruff 0.16.x with an explicit `[tool.ruff.lint] select`, unify the four disagreeing ruff version declarations, and clear the 481 findings that result — without changing package behaviour.

**Architecture:** Config first (turns CI red), then autofixes, then manual fixes ordered by how much judgment they need, then the one deliberate behaviour change (`settings.as_dict` rename), then tests/examples plus the docs re-sync they force. Six tasks, each ending green on the full test suite.

**Tech Stack:** ruff 0.16.x, uv, pytest, nox (Python 3.12/3.13/3.14 × Django 4.2/5.2/6.0), pre-commit, Taskfile.

**Spec:** `superpowers/specs/2026-07-27-ruff-latest-upgrade-design.md`

**Branch:** `feature/ruff-0.16-explicit-select` (already exists, spec already committed as `7bfeb67`)

## Global Constraints

- Line length **120**; quote style **double**; indent **space**. Do not change these.
- All `CrudView` class attributes keep the `cv_` prefix. Never rename one.
- **No `--unsafe-fixes`** anywhere in this plan.
- **No version bump, no tag, no release.** The `as_dict` rename goes under `## Unreleased` in `CHANGELOG.md`.
- Commits must use **explicit pathspecs** (`git add <paths>`), never `git add -A` or `git add .`.
- Run ruff via `uv run ruff` inside the repo. If a command misbehaves because of an inherited virtualenv, prefix with `env -u VIRTUAL_ENV` (known gotcha in this project).
- Tests run from the `tests/` directory: `cd tests && pytest`.
- Only commits D (rename) and the `B905` decision in C may change behaviour. Everything else must be behaviour-preserving.
