Access trace mockup

For django-crud-views #370: the Access check card on the manage page, and cv_access on the command line.
How to read this
  • Static mockup: the forms don't submit. They show the result of the values already typed in.
  • The data is the tabler-test demo's: 25 customers, sam holds object grants (view, change) on customers 26 to 29 and the model permissions add_customer, view_order, add_order, change_order. order is a core ViewSet nested under the Guardian ViewSet customer. The outcomes are worked out by hand from that data, not produced by code.
  • Rendered in the Tabler theme. Upstream ships stock Bootstrap 5 markup with classes from the class registry (D-16).
  • The card only exists when the project sets CRUD_VIEWS_MANAGE_ACCESS_TRACE (D-15).
  • This file has a <style> block and no script. The implementation has neither inline styles nor inline scripts (D-16); the expandable lines are native <details>.
